# 專案檔案模板

沿用使用者提供的文件格式及現用欄位。以下欄位供建立專案檔、補齊設定與交接使用；不適用的欄位依作品刪減或註明，缺少但會影響下游的資料列入待補清單。

```text
專案檔案｜名稱、版本、最後更新

一、專案基本資料
專案名稱、作品類型、媒介／發佈平台、集數與時長、目標受眾、核心標籤、參考作品、核心 logline

二、風格與調性
視覺風格：整體畫風、色調、鏡頭取向
敘事調性：主基調、節奏、禁忌
語言風格：對白、旁白、笑點

三、世界觀設定
時空、核心規則、主要場景、衝突源

四、人物檔案（逐角列出）
名字、一句話定位、外形、性格三層（表層／深層／陰影）、說話風格與樣例、角色弧線、關係

五、已確定的劇情主線
適用的大綱或其版本、關鍵情節節點、已確認的關鍵場景與台詞
連載附集首／集末狀態、鉤子與承接；改編附必留事件、來源及揭露進度

六、本次工作
指定的交付、涵蓋範圍與特別要求

七、協作約定
核准的人設、對白風格、鎖定詞句與不可更改的設定、採納的對標規律（如適用）

八、待補充清單
未確認的項目、目前採用的假設、需由誰確認及影響範圍
```
