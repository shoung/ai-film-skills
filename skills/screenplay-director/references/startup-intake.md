# 新創作啟動 Intake

本文件用於開始新創作或重新定義方向。先讀取本輪需求、既有劇本、專案文件與此前已確認的決策。

## 先判斷工作類型

- **全新劇本**採用下方的分輪訪談，包括從靈感開發新作品，或首次把原著轉為劇本且尚無核准改編方向。已有核准創作綱要且足以支撐本次交付時，直接接續。
- **已有劇本**：先讀取劇本和相關設定，辨認使用者要診斷、改寫、擴寫或轉成製作文件；保留明確鎖定的內容。
- **續作**：先讀取前作、人物與世界設定及已確認結局；只詢問續作新方向或連續性中真正缺少的決策，不重新訪問前作設定。
- **局部修訂、純格式轉換或維護**：依指定段落、檔案或規則直接處理。

## 全新劇本分輪訪談

1. 先從對話、可讀的專案檔案與已完成的原著分析查明事實。沿用已回答、已核准或素材已明示的資訊。若新指示與既定設定有實質衝突，優先處理該衝突。
2. 把前提已確定、可彼此獨立回答的重要問題放在同一輪。**首輪通常 2–4 題**，題數按實際缺項調整。只有一個前提需要先決定時，就先問那一題。若某題的選項或理由取決於本輪另一題的答案，把它留到下一輪。案情較大時，可按已確認的範圍把可回答的問題分組。
3. 全程以繁體中文對話，用編號列出每題的主題與具體問題，附一個建議方向和簡短理由。可用選項或開放式提問，讓使用者按題號回答、提出別的方向、暫留未定或授權代決。一輪問完後等回覆，再根據答案調整下一輪，承接已定的內容。
4. 依本案需要釐清故事方向、敘事框架、世界與場景設定、時代、角色目標、性格、外顯特徵、彼此關係、衝突與代價，以及媒介、篇幅、調性或必留內容。總題數不固定，持續處理會實質改變作品的未決事項，直到足以開工。素材中的細節與使用者授權代決的事項可直接沿用或作判斷。
5. 將已定方向、鎖定條件與重要假設整理成短摘要，取得使用者確認後再開始實質寫作，包括正式方向卡、角色設定、大綱與劇本正文。使用者明確委託代決或要求略過特定決策時，依授權處理該部分，其餘重大未決事項依輪次確認。已有適用的核准創作綱要、明確委託全部方向，或明確要求跳過訪談時，帶著既定決策或已採用的假設直接執行。

例如，使用者已確定要寫一部姊妹接手老照相館的家庭懸疑劇，但故事年代和姊妹關係仍開放，可以同輪提問：

1. **故事年代**　你想把故事放在底片仍普及的年代，還是今天？建議選今天，讓舊底片和家人手機裡的影像留下兩種線索。
2. **姊妹關係**　故事開場時，姊妹已經疏遠，還是仍能互相信任？建議先保留日常信任，讓查到第一個秘密之後的疏離有具體轉折。

若要問數位相簿如何參與揭密，先等年代確定，再放進下一輪。分輪提問方式參考 [grill-me 的現行說明](https://github.com/mattpocock/skills/blob/d65391149dbb5fe76478e76fa8d5122b2aa5a70e/docs/productivity/grill-me.md#what-it-does)。

## 其他創作與製作的補問

只補會實質改變方向、結構或可執行性的缺項，每輪最多 2–3 題。這個上限適用於一般創作與製作補問。全新劇本依上方分輪訪談辦理。已知資訊直接沿用，授權代決的細節依授權處理，並簡短標示重要假設。

## 依交付類型挑選問題

下列是可選問題庫，不是每案必填表。只挑出本次交付真正缺少且重要的項目：

- **劇本／故事**：目標與受眾、發布平台、片長或篇幅、現有劇本／素材、要交付大綱或完整劇本、不可改動的設定。
- **視覺資產**：現有劇本與角色／場景／道具素材、正式核定卡與版本、視覺風格、鎖定的外觀或狀態、需要提示詞還是實際圖片。比例／解析度只在會改變實際圖片製作且無法推斷時詢問。
- **分鏡／影片提示詞**：現有劇本與素材、發布平台、目標片長、畫幅比例與解析度、視覺風格和鎖定內容、要交付八欄表或可直接提交的哪種模式 prompt。目標模型只在撰寫模型專用 prompt 而無法由上下文判定時詢問；預算與模型細節只在使用者要求實際生成或製作時詢問。
- **成片製作**：受眾與發布平台、片長、比例／解析度、劇本與正式核定卡版本、風格與不可改內容、交付形式；模型和預算只在需要實際生成時補問。

例如，使用者已有劇本並啟動新影片製作時，可在同一輪詢問交付形式、發布平台和畫幅限制。模型與預算依實際生成或製作範圍補問。

## 識別標記

全新創作任務在對話中顯示 [SHOUNG 文字標記檔](../assets/shoung-logo.txt) 的完整內容一次，原樣獨立呈現（可用純文字 code block）；不要只憑記憶縮寫或改造檔案內容。續作、新階段、一般交接、局部修改、維護、列清單、安裝與解說不重複顯示。此標記只供對話識別，永遠不得寫進作品正文、模型 prompt、參考圖標註或生成媒體。

## 下游交接

交接時攜帶已決定的方向、確認或授權紀錄、版本、鎖定內容、未決事項與指定下一步。下游技能沿用這些決定，只有遇到影響自身交付的新缺項時才依本次任務範圍補問。
