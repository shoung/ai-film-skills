# 原生專案讀取契約

創作台先辨識本套件的原生文件，也相容 drama-skills 的 EP／SC／SHOT／MOTION 格式。結構視圖可回查專案原文，匯入時保留源檔。

| 文件 | 本套件結構 |
|---|---|
| 劇本 | `1-1 場景名 日 內`；可用 Markdown 標題及 `／` 分隔，時間碼可附於標題後。一般說明如「本版鎖定」不是場次；人物行、動作、說話者與括號提示保留。 |
| 視覺資產 | 角色／場景／道具類別下的 `### @資產名`，以及 `#### @資產名_狀態`；保留父子關係與文生圖提示詞。 |
| 分鏡 | 每鏡一列，固定欄序為「編號、畫面描述、攝影機描述、聲音描述、旁白對白、時長、影片生成方式、畫面prompt」。讀取 Markdown、CSV，舊九欄多出的「修改」放在附註。圖片與 QA 放在鏡頭詳情。 |
| 影片提示詞 | 依鏡號或生成群組的獨立請求，可分多檔；H3 三個核心欄位、JSON／文字區塊及 Seedance 提示詞正文維持原文。一份多鏡請求仍只是一份請求。 |
| 圖片提示詞 | `@` 狀態資產、單幀或圖像段落的實際提示詞；區分生圖正文與素材／後製說明。 |

## 主表與其他輸出

在專案入口用 `[分鏡主表](相對路徑)` 明示主要來源。沒有宣告時，預覽優先使用 Markdown，並按路徑排序選擇。同集保留各來源對照，`<br>`、儲存格換行與跳脫等表示差異按解析後的內容比較。

遇多個主表宣告時，預覽暫用排序首項，並提示確認來源。沒有宣告主表且內容確有差異時，分集顯示摘要，逐鏡可查差異欄位。同檔重複鏡號或來源間鏡號缺失、多出均會提示。不同版本及不同集分開呈現。素材依登錄、連結及有明確邊界的鏡號命名關聯，缺失或歧義時會提示。無法辨識的內容仍可讀原文。

## 剪輯單是選用的後製旁表

剪輯旁表記錄實際採用的檔案、取用區間和組裝方式。需要處理素材取捨、入出點、字幕、配音、音效或交付規格時再建立。創作台依剪輯資料顯示時間線，也能在沒有剪輯單時顯示實際素材候選。未對應現有鏡號的素材和實際成片會各自標示。

為避免教學錄影按鏡號誤關聯為影片候選，名稱恰為 `教學素材`、`教学素材` 或 `tutorial-assets` 的目錄及其子目錄中的影音圖檔不納入作品媒體掃描；其中的文字文件仍可瀏覽。正式作品素材請放在其他目錄。
