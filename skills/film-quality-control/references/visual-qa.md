# 只讀審片員：獨立視覺 QA、修復與重審

除本頁逐圖檢查，也須依 [台詞與時長審核](timing-and-dialogue.md) 核對每段影片 prompt 的台詞、語速、情緒、動作與秒數。靜幀看起來正確，不代表影片有足夠時間完成表演；該項按生成段另記 timing_review。

## 正式來源與審核隔離

正式角色卡應包含可識別的臉、髮型、妝造與身形；依劇情另綁定已核准服裝狀態。所有會露臉或需辨識身份的配角也要有正式依據，不能只替主角建卡。場景、關鍵道具及其狀態亦指定正式版本。若使用者已提供可用照片，不必強迫重做卡；將該圖登錄為正式來源即可。缺來源時先完成可做的結構工作並明列待補，不捏造核准。

實際呼叫獨立 QA 子代理；其任務是讀取卡片、靜幀、前後鏡與對應分鏡／prompt，不能修改產圖或正式卡。QA 不使用生成者「我認為很像」的自評當證據。主代理可批次分派數張圖，但每張都須有結果；依專案規定選模型，沒有規定就選可看圖且能勝任者。本專案 AGENTS 若規定 Luna，必須使用 Luna。

用 view_image 或相應可視工具實際看圖。讀文字路徑、算 hash 或列出圖片清單均不等於看圖。QA 紀錄應能對應真實的子代理 ID、被看過的檔案／雜湊與具體觀察；不能先填 PASS 再補看圖。

## 每張必查

| 維度 | 要找的差異與對應證據 |
|---|---|
| identity | 臉型、五官相對位置、髮線／髮型、身形；禁止以「同是年輕美女」代替身份核對 |
| wardrobe | 上下身款式、顏色、領口、肩帶、配件、鞋襪與污漬／濕乾等狀態；裁切未見的部分如實註記 |
| makeup | 妝色、濃淡、痣、飾品與其他鎖定外觀；區分光線造成的合理色差 |
| scene | 可見牆面、門窗、家具、地毯位置、材質、光向與色溫；換鏡位不等於背景全部重排 |
| continuity | 前後鏡的道具位置、持物手、視線、軸線、人物站位、動作起訖及狀態變化是否有劇情理由 |
| prompt_alignment | 鏡號、說話者、景別、表情觸發時機、單鏡構圖、方向與實際比例／像素；一張分鏡單幀不應是拼圖或多格分鏡 |

不可見部分不推測已通過；可在證據寫「鞋未入鏡」，或將整項確實不適用的維度列 N/A 並附原因。只有無人物插鏡等實際不適用才能 N/A，臉太小、遮住或來源缺失應列 uncertain／pending，不能濫用 N/A。

## 前後鏡與分階段狀態

1. 新圖先對正式卡與已存在的前鏡。下一鏡尚未有圖時，標記 provisional／待補鄰鏡，不進最終交付通過名單。
2. 序列完成後，逐圖對前後最近已提供的靜幀。同一鏡有多張起訖／關鍵幀時也按時間序相互核對，再銜接下一鏡；序列首張只需後張，末張只需前張，只有單張則註明無鄰鏡。首尾幀不能只審一張。
3. 非相鄰時間的跳接、跨場、換裝、污漬增減，需在分鏡與登錄中有理由，不能當成漂移掩飾。
4. 同一套場景反打允許看到另一面，但可見門窗、家具與人物關係必須符合正式空間。近景不用強迫塞入每件家具來證明場景。

## QA 結果與修復

- **pass**：實際看圖且所有適用項目符合，有逐項證據。
- **fail**：指出具體差異與位置，標明嚴重度、影響範圍及建議修復。臉、服裝、妝造、場景漂移屬必修項，不能用平均分抵銷。
- **pending / uncertain / provisional**：缺來源、圖不可辨識、缺鄰鏡或無獨立代理能力。告知限制，不冒充 pass。

修復時先修錯誤素材、參考綁定、鏡頭設計或 prompt。**禁止改正式核准卡來迎合錯圖**。只有使用者另行批准新的創作方向，才建立新版正式卡並使受影響舊 QA 失效。

一次先修最小必要範圍，檢查修後圖及其前後關係。兩次同類修復仍失敗就重新檢查來源、鏡位或生成模式，提出可執行替代方案；不無限重抽或擅自增加成本。換圖、正式卡版本／hash、鏡序或鄰鏡變更後，重審受影響圖與鄰鏡，而非重做全片。保留修復前版本供追溯，不在未獲授權時清空素材。

## QA 子代理任務模板

```text
你是獨立視覺 QA，只審核，不改圖或正式卡。
請實際看以下檔案：[正式角色/服裝/場景/道具卡、當前圖、前後圖的絕對路徑]。
分鏡與提示詞：[鏡號、動作起訖、說話者、景別、時間碼與規格]。
依 identity/wardrobe/makeup/scene/continuity/prompt_alignment 逐項記錄觀察。
每張輸出 pass/fail/pending、所見具體依據、差異、修復建議；不適用須附理由。
缺來源或無法辨識不得通過；不得修改核准卡去合理化產圖錯誤。
回報實際看圖的檔案與代理身份，讓主代理保存真實證據並填入版本登錄。
```
