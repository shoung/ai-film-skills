# 八欄分鏡表格式

適用於分鏡表的建立、改寫與格式轉換。分鏡表是供人閱讀、剪輯及準備素材的製作文件，不是模型專用提示詞正文；本規範不改動 Seedance 或 MiniMax H3 的欄位、參考標籤與對白語法。

製表前讀取同目錄的 [分鏡表模板](storyboard-table-template.md)。除使用者明確要求其他格式外，固定使用下列八欄，欄名與順序不得自行改動：

| 編號 | 畫面描述 | 攝影機描述 | 聲音描述 | 旁白對白 | 時長 | 影片生成方式 | 畫面prompt |
|---|---|---|---|---|---:|---|---|

## 欄位用途

| 欄位 | 填寫內容 |
|---|---|
| 編號 | 每鏡唯一且穩定的編號；既有鏡號沿用，不因轉格式重編。分組時也保持全片唯一。 |
| 畫面描述 | 當鏡年代、場景、必要角色與可見動作；有需要才以儲存格內換行補場次、暫估時間碼、道具起終狀態、字幕或揭示控制。避免把全片故事大綱塞進單鏡。 |
| 攝影機描述 | 景別、構圖、機位、角度、鏡頭運動及必要鏡頭資訊；畫幅、風格、調色、景深、畫面剪接與素材重用亦整併於此欄。沒有實際用途時，不硬填焦段或攝影術語。 |
| 聲音描述 | 現場聲、音效、必要配樂及聲音轉場；跨鏡對白的起句、延續與收尾位置也在此註明，與畫面時間線清楚區分。 |
| 旁白對白 | 說話者及原句。保留既有台詞文字、順序、語言、口音與必要的畫外音標記；多句可在同格換行。無台詞用「—」或空白。 |
| 時長 | 單位為秒，以數值填寫；未知時填「待定」，不捏造數值。使用既有時間規範與使用者限制；剪輯暫估須明示，不能把估值當成模型介面上限，也不能為湊總長壓縮必要動作。 |
| 影片生成方式 | 依已確認模型與素材，填具體建議模式及必要輸入；模型未定填「待確認模型」，素材未建立即標明。實拍、素材重用、照片定格與後製排字如實標註，不必每鏡都交給模型重新生成。 |
| 畫面prompt | 依本鏡構圖及起始狀態填短畫面／首幀試作提示詞，或沿用使用者已提供的內容。未要求撰寫、資訊不足或模型未定時，可填「待編寫」或「沿用既有素材」。不得把它標成已完成的模型專用影音請求；完整生成提示詞依目標模型規則另行組織。 |

## 編排與對照

- 每鏡一列。可以按場次分成數張同欄表，但不能把同一鏡拆成兩套不同欄位的主表，也不能自行增刪欄位。額外必要資訊放入對應儲存格或表外簡短說明。
- 使用使用者指定的檔案格式；未指定時交付 Markdown 表格。CSV 等表格檔沿用同一組八欄，不另造一份欄序不同的主表。
- 表外說明僅列全片共用設定、秒數單位、時長是否暫估及理解本表所需的模式對照。不得從範例繼承畫幅、年代、角色數、風格或總片長。
- Markdown 儲存格內用 `<br>` 保留換行，跳脫 `|` 等會破壞表格的符號；CSV 的逗號、引號與換行依標準 CSV 規則包覆。
- 需要時在表末附合計列，只累加「時長」欄的已知數值。若有待定時長，明示合計不完整；有可計算表格能力時使用合計公式，靜態文件則寫明暫估總秒數。
- 重播或重用鏡頭仍按成片播放次數計入時長；生成方式欄指出原素材編號，不另寫成重新生成的鏡頭。
- 跨鏡對白只在起句鏡記完整原句，後續鏡在聲音欄標「延續」與結束位置，不把延續當作第二句重說。若既有稿已明確拆句，保留其拆分並核對完整原文。
- 道具交接、服裝改變與起身／坐下等動作須可接續：前鏡終態是後鏡起態，不能因畫面prompt寫成完成態而提前發生動作。回憶與當下的調色、聲音及道具差異寫在對應欄，不靠隱藏身分或無依據的效果補敘事。

## 製表與生成提示詞的邊界

- 純分鏡表或格式轉換可以先完成；沒有模型選擇時，不因此阻塞已知內容的編排，也不擅自替使用者選模型。
- 開始撰寫可直接提交的模型專用提示詞前，依 skill 既有模型分流流程確認模型與模式；H3 的欄位名稱、段序及標籤與 Seedance 的正文格式照各自規則保留。
- 外部分鏡編號是對照索引，不應混入模型正文的動作、觸發、台詞或切鏡指令。每次獨立提交的參考素材與說話者仍須能解析。
- 畫面prompt若只供首幀構圖試作，明確標示用途。它不能取代動作過程、聲音與對白，也不能把單幀畫面所描繪的狀態誤當成整段影片已完成。

## 交付前核對

確認八欄名稱與順序、鏡號及台詞對照、時長與合計、模式和實際素材需求、調色與聲音轉場，以及道具起終狀態。格式轉換不得刪掉來源的關鍵資訊；未知項如實標示。模板只提供格式和中性示例，不含個別專案的設定。
