# 分鏡表、單幀與影片提示詞的對應

## 先定義一鏡

一鏡是同一機位或連續運動攝影機拍下的連續時間／空間。平移、推近、連續環繞、由物件移焦到人物，都可能仍是一鏡；切到另一機位、越肩反打、插入手機畫面再切回、跨時空蒙太奇則是多鏡。先讀提示詞語意，再數 Shot 標籤。角色互望、演員轉頭或台詞換人，本身不必然切鏡。

分鏡表保持原有八欄，每列一鏡，使用 S001、S002 等穩定鏡號。生成群組 G001 可包含多個鏡號，不把整段對話塞成一列逃避檢查。拆鏡後檢查動作接續、視線方向、台詞與總時長，不憑空補一鏡遷就尾幀。

## 模式門檻

| 模式 | 本流程准許鏡頭數 | 圖片用途 |
|---|---:|---|
| T2VA 文生影 | 一鏡或多鏡，依目標模型能力 | 不帶圖片；有正式身份圖並要求沿用時，應改可用的參考模式 |
| I2VA 首幀圖生影 | 恰一個連續鏡頭 | 一張 first_frame，作該鏡實際起始畫面 |
| FL2VA 首尾幀圖生影 | 恰一個連續鏡頭 | 一張 first_frame 與一張 last_frame；同鏡可連續到達的前後狀態 |
| L2VA 尾幀圖生影 | 恰一個連續鏡頭 | 一張 last_frame；只有目標模型確實提供此模式才使用 |
| Ref2VA 參考生影 | 一鏡或多鏡，依目標模型能力 | 身份、場景、道具或構圖參考；各圖用途明確，不承諾硬首尾幀 |

I／FL／L 不可含肯定的「切到／反打／jump cut／montage」等鏡頭變更要求。否定指令如「不要切鏡」「no cuts」不是切鏡要求。檢查器僅能捕捉部分寫法；代理仍須讀全文，包含同義詞、時間碼與圖像起訖是否暗示不同機位。

多鏡 I／FL／L 退件後，依使用者優先項目處理：要保留固定構圖與身份就拆成多次單鏡生成再剪接；要模型直接產生切鏡就改用確認可用的 T2VA／Ref2VA，重新標記素材用途。不得自行犧牲已鎖定的角色一致性，或聲稱一張首幀可保證後續反打身份。

## 圖與提示詞逐鏡核對

- 首幀應是動作起點。例如台詞觸發後才翻白眼，首幀不可已翻白眼；尾幀則對應收束狀態。
- 反打是不同鏡號；兩人的左右位置、視線與攝影軸線應能對上。單人中景、近景、越肩鏡的臉須有足夠辨識度；景別按敘事安排變化，不把全片機械地統一中景。
- 若需展示地毯污漬或場景特定區域，可用該區域插鏡；只有環境理解確有必要才用遠景。這是針對角色辨識與敘事需求的判斷，不限制其他題材的合理遠景。
- 無人物的道具特寫可將身份／妝造檢查列有理由的 N/A；背景被裁掉不代表場景錯誤，但能看到的幾何、光向與材質要一致。
- 畫面尺寸與構圖依本次規格：例如直式 9:16、1080×1920 不能用橫式圖硬壓扁；人物設定卡可另用已核准的比例。逐一檢查實際檔案尺寸，不只讀檔名或 prompt 宣稱。
- prompt 的模式、shot_ids、圖片標籤、台詞說話者、時間碼、起訖狀態須與分鏡及素材一致。圖片角色朝向錯誤不能只靠 prompt 文字視為修好。

## 正反案例

**合法 FL2VA**：S001，小琪在同一單人近景從平靜看人到聽完話後挑眉，攝影機緩慢推近，6 秒無切鏡。首尾圖都是同一機位可連續到達的狀態。

**退件 FL2VA**：標題只寫 [Shot 1]，正文卻「0–3 秒小琪，3 秒切朋友反打，5 秒切回小琪」。實際三鏡，必須改模式或拆成 S001–S003。

**合法多鏡 Ref2VA**：G001 連結 S001 小琪近景、S002 朋友越肩反打；兩角色卡分別標記身份參考，場景卡標記場景參考，逐鏡指定角色與視線。能力與參考數量上限仍依目標模型查證。
