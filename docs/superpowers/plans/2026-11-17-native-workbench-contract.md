# 原生創作格式讀取修正

使用者已授權修正創作台與既有 skills 的資料契約。本輪修 bug，不改寫劇本、提示詞或真專案資料。

根因已由 localhost 畫面與程式追蹤重現：先送上游 parser 產生錯誤，再做八欄／檔名補救；H3 只讀單檔，MD／CSV 無條件警示，多次重複；原生場次與 @狀態資產未結構化。

## 決策

- 以既有 skill 原生格式為主：`1-1 場景 日/夜 內/外`、`@資產_狀態`、八欄 MD／CSV、H3／Seedance 請求。上游格式保留兼容。
- 解析器按文件類型分流，成功的原生文件不再產生上游格式錯誤。保留真正欄位錯誤、缺少媒體與來源歧義。
- 主表依明確宣告選取；同源序列化差異不報錯，真差異仍可追溯並集中呈現，不顯示幾十條同文警示。
- 剪輯單有實際取用入出點、聲音／字幕落點的價值，保留為選用後製旁表；不增加八欄，也不作原生流程的必填待辦。
