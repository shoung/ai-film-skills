# 劇本創作 Skill 整合使用說明

## 推薦入口

優先使用：

`0.劇本總控 · 從靈感到可執行劇本 Skill v1.0.txt`

它負責判斷階段、調用專家、管理版本交接，並最終輸出《最終可執行劇本包》。

## 專家 Skill 順序

1. `1.劇本框架 · 項目檔案生成 Skill v2.0.txt`
   - 用途：靈感 → 項目檔案 / 大綱 / DNA 報告
   - 對應階段：S1-S3

2. `2.劇本寫作 · 大綱擴寫與修訂 Skill v1.0.txt`
   - 用途：項目檔案 + 大綱 → 劇本初稿 / 修訂稿 / 臺詞整合稿
   - 對應階段：S4 / S6 / S8

3. `3.劇本醫生 · 圓桌會診 Skill v1.0.txt`
   - 用途：劇本 / 大綱 → 多視角會診報告 + 修改任務清單
   - 對應階段：S5

4. `4.臺詞專家 · 全量診斷 Skill v1.0.txt`
   - 用途：結構基本鎖定的劇本 → 臺詞診斷 + 臺詞替換清單
   - 對應階段：S7

## 總體流程

用戶靈感
→ 劇本總控判斷階段
→ 劇本框架生成項目檔案和大綱
→ 劇本寫作生成初稿

→ 劇本寫作整合臺詞
→ 劇本總控輸出最終可執行劇本包

## 推薦劇本輸出格式

短劇、短視頻、微電影、AI 視頻生成項目，推薦默認使用“中文短劇拍攝稿格式”，而不是英文工業劇本格式。

格式示例：

```text
1-1 青槐路 夜 外
人物：阿遠 老周
△暴雨砸在外賣箱上。阿遠停在舊牆前，低頭看手機導航。
阿遠（壓著煩躁）：哥，您這地址……是住牆體裡嗎？
△老周撐著傘站在巷口，手電光從牆面移到阿遠腳邊。
老周（聲音不高，尾音壓低）：有人找得到，有人……找不到。
手機提示：預約單已預付。超時將影響評分。
```

核心規則：

1. 場次頭使用 `1-1 場景名 日/夜 內/外`。
2. 本場人物單獨列出：`人物：角色 A 角色 B`。
3. 動作、畫面、調度可用 `△` 開頭，但一個 `△` 表示一個連續動作段，不是一句話一個。
4. 對白使用 `角色（狀態/發聲提示）：臺詞`。
5. 手機提示、系統音、字幕可以單獨寫成執行行。
6. 動作發生轉折、視角切換、時間跳躍、人物關係變化時，再另起新的 `△`。

## AI 配音標點前置設計

如果劇本後續要進入 AI 配音、AI 視頻生成、數字人或 TTS 工作流，臺詞標點要在劇本階段就設計好。

標點不是裝飾，而是表演提示：

| 標點 | 作用 | 適合情緒 |
|---|---|---|
| 逗號 | 小停頓、組織語言 | 思考、試探、安慰 |
| 句號 | 收住、落地 | 平靜、剋制、冷淡 |
| 感嘆號 | 加重、強調 | 警告、憤怒、興奮 |
| 問號 | 尾音上揚 | 疑問、懷疑、試探 |
| ？！ | 質問、爆發 | 震驚、憤怒、不敢相信 |
| 省略號 | 情緒卡住 | 難過、緊張、捨不得 |
| 破折號 | 情緒轉折 | 遲疑、意識到真相、強調 |
| 波浪號 | 尾音變軟 | 撒嬌、輕鬆、親近 |

推薦寫法：

```text
阿遠（語速慢下來）：你到底……是誰？
門內女人（OS，聲音放輕，尾音穩穩落下）：放門口吧，阿遠。
阿遠（聲音很輕，尾音發虛）：我……吃了。
```

不要只寫：

```text
阿遠難過地說：我吃了。
```

要寫成：

```text
阿遠（聲音很輕，語速慢下來，尾音發虛）：我……吃了。
```

## 配音友好檢查

每次輸出正式劇本後，建議檢查：

1. 關鍵情緒臺詞是否有明確停頓。
2. 不同角色是否有不同氣口。
3. 是否存在過度感嘆號、省略號、問號。
4. 關鍵臺詞是否補了聲音大小、語速、呼吸、尾音。
5. 是否有容易被 AI 念成“配音腔”的句子。

建議後續默認保留兩版：

1. **中文拍攝稿版**：給導演、演員、分鏡、製片看。
2. **配音標點版**：給 AI 配音、數字人、視頻生成使用。

## 視頻提示詞下游接口

如果後續要把劇本轉成 Seedance / 可靈 / Runway 等視頻提示詞，劇本階段還要額外照顧“鏡頭生成”的需求。

下游最需要劇本提供：

1. **臺詞可逐句提取**
   - 對白、OS、VO、手機提示、系統音都要單獨成行。
   - 不要把臺詞揉進動作描述裡。

2. **空間調度自然清楚**
   - 每場用動作行寫清固定空間關係。
   - 不確定的方位不要亂寫，避免下游腦補。

3. **人物方位自然清楚**
   - 誰在門口、誰在牆邊、誰在收銀臺後，要融入場景開頭的動作描寫。

4. **人物移動關係清楚**
   - 寫“從 A 到 B”，不要只寫“走過去”。

5. **心理描寫可拍**
   - 少寫“他崩潰了”，多寫“他攥緊貼紙，嘴唇發抖，勺子停在半空”。

6. **關鍵道具有視覺描述**
   - 材質、顏色、狀態、是否破舊、是否有辨識度。

7. **長臺詞提前拆分**
   - 單句超過 40 字，後續很難塞進 15 秒視頻組，建議劇本階段就拆。

推薦場次寫法不是增加字段表，而是在劇本正文裡自然寫清空間和調度：

```text
1-5 舊樓樓道 夜 內
人物：阿遠 門內女人

△舊樓樓道很窄，404 門在走廊盡頭，門縫裡透出一點暖光。阿遠拎著熱粥站在門外，外賣箱靠著牆，手機訂單頁還亮著。
△門內女人始終不露面，聲音從門縫後傳出來。
△碗蓋上貼著一張泛黃的小貼紙，邊角捲起，上面是兒童筆跡：阿元的飯。
門內女人（OS，聲音放輕）：放門口吧，阿遠。
```

複雜場面也優先用自然動作寫人物方位和移動關係。只有多人調度、追逐、打鬥、群像場面等確實容易混亂時，才在場後加一句“調度備註”，不要把常規場次寫成工程表。

每次正式劇本輸出後，建議追加：

```text
【視頻提示詞接口檢查】
1. 臺詞是否可逐句提取：是 / 否
2. 每場空間關係是否已在動作行中自然寫清：是 / 否
3. 人物方位和移動關係是否不用下游腦補：是 / 否
4. 抽象心理是否已轉為可拍動作：是 / 否
5. 關鍵道具是否有視覺描述：是 / 否
6. 是否存在超過 40 字的長臺詞：是 / 否
7. 是否存在旁白 / 心想 / 回憶等需轉畫面的標註：是 / 否
```
