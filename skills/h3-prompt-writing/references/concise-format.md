# 精簡生成提示詞格式

<!-- 維護來源：skills/video-prompts/references/concise-format.md -->

## 模式與分組

每個生成請求是獨立的提交與審核單元，可涵蓋一鏡或多鏡。依敘事因果、台詞與動作時長、介面支援、重抽成本和素材清晰度決定分組。複雜道具、精細動作或關鍵表情特寫可單獨生成，緊密因果或需要連續表演的鏡頭可合併。

- 角色說話、畫外台詞或旁白所在的請求一律採 **Ref2VA**。有可用首幀、暫無聲線檔或後製才接入畫外聲時，仍照此分組。後製接入點記在製作備註，已生成的台詞只做一次。無語句的音效不算發話。
- 無發話時，首幀足以控制就用 **I2VA**，需要鎖定尾態且首尾在同鏡可連續銜接時用 **FL2VA**。兩種方案都無法滿足必要控制才改用 **Ref2VA**，並在備註交代理由。可製作但尚缺的幀先標待補。
- 本套件的 I2VA、FL2VA、L2VA 限一個連續鏡頭。多鏡可逐鏡生成後剪接，或採經介面驗證的多鏡模式。T2VA 不需附圖，使用已確認模式，並遵守發話鏡規則。

在套件內另可查 [模式與逐鏡核對](../../film-quality-control/references/mode-and-shot-rules.md#生成模式選擇)。單獨安裝沿用本節規則。

## 請求自足與方位

- 同一請求內，後鏡可回指前鏡。跨請求需重建該段初始構圖、姿態與道具狀態，確有提交首幀／接續幀時可由圖提供。角色卡和道具卡只涵蓋本次指定的參考用途。可提交的模型正文只引用實際附件。已指定但尚未上傳的音檔標籤可在草稿暫列，於製作備註標待上傳，提交前核對。
- 構圖、光線、視線和運動以當前鏡頭的畫面左／右、前／中／後景及靠近／遠離鏡頭表達。角色的生理左／右另寫清楚，切鏡、反打或環繞後重建方位。
- 世界方位以已確認的機位或可見物換算。方向未定且影響構圖時補問。鎖定台詞、地名或畫面原文字樣照原樣保留。

## 正文與時間

正文預設繁體中文，保留模型專用欄位、標籤、語法與鎖定台詞。需要標示的敘事節拍預設採 **0.5 秒**網格。鎖定時長、實測音軌與指定剪輯點保留原精度，時間戳依介面語法呈現，例如 H3 的 `00:00.000`。片長限制取自已確認的模型與介面。群組 ID、分鏡對照、估算、掛圖清單、品管與寫作回執放在可複製正文之外。
