# 本地 AI 影視創作台

使用 [啟動與停止](SKILL.md#啟動與停止) 的指令開啟專案。

## 閱讀流程

全劇總覽提供分集製作進度與下一步。進入一集後，從頂部切換概況、劇本、設定、分鏡、提示詞、成片、審查；全部檔案是次級入口。

分鏡可切換卡片和表格，也可點節奏條選鏡。分鏡詳情隨選鏡同步顯示圖片、首尾幀、可用片段、台詞、設定、提示詞與審查。桌面並排顯示圖詞，窄版改為上下排列。提示詞可展開及複製。只有整張宮格時會標示鏡號範圍，缺少單鏡圖片時會提示。

可先在「成片」頁瀏覽影片候選，無須先準備剪輯單。準備匯入或排查來源差異時，見 [原生專案讀取契約](references/native-project-format.md)。

## 編輯與 QA

- **編輯表格**支援已辨識的 `.md`、`.markdown` 分鏡表。來源有差異時先確認要修改的檔案。可編輯、增刪或移動分鏡列，既有鏡號固定，新增列可填寫鏡號。儲存只更新所選檔案的分鏡列，保留表外說明及小計。
- **編輯原文**支援 `.md`、`.markdown`、`.csv`、`.txt`，可用於 CSV、舊版逐鏡標題或無法辨識的表格。HTML 原始碼、JSON 與 QC 登錄以唯讀方式顯示。

如果儲存時提示版本衝突，先載入最新檔案，再合併要保留的內容。舊版 QA 登錄供回查，創作內容修改後需重新審核。 [儲存與品管](SKILL.md#讀取與儲存)
