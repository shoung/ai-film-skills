# 劇本格式與製作交接

優先沿用核准稿或使用者指定的格式。以格式本來要支援的工作為準，拍攝稿讓導演、演員和各部門找到場頭、動作、發話及聲音；閱讀稿可用敘事帶出內在視角。選讀本次相關格式。

## 標準影視劇本（M1）

場頭包含場號、內外景、地點及日夜。第三人稱、現在時寫可見動作，人物名與對白分行，適用時標 O.S.（畫外）、V.O.（旁白）或 CONT'D（續說）。轉場如 FADE IN、CUT TO 按交付格式使用。

```text
01  INT. 舊照相館 — 夜

阿寧把一個相框翻面。背板上貼著一張泛黃收據。

                  阿寧
            （放慢語速）
            這張不是我們家的。
```

## 小說化敘事劇本（M2）

用可定位的場景標題分段，沿用核准的敘事人稱、視角與時態。可將感官、心理及對白融入敘事，仍要能明確辨認說話者及場景轉換。用於後續拍攝時另將必要心理轉為可見行動或可聽聲音。

```text
【場景一　夜・舊照相館】
阿寧認得收據上的字。每次家裡缺錢，母親都用這個字把帳拉過一行。
她把背板翻向妹妹。「這張不是我們家的。」
```

## 中文拍攝稿

適用於收到中文拍攝稿範例或需要易於執行的中文短劇、短片及 AI 分鏡交接時。場頭標場次、場名、日／夜與內／外。動作段可用 `△` 分段，一段為連續動作，視線、時間、調度或關係發生轉折時另起。人物發話、畫外聲、手機提示、音效和字幕依用途分列。

```text
1-1 舊照相館 夜 內
人物：阿寧、妹妹
△阿寧把相框翻面。妹妹向前一步，停在桌角。
阿寧（放慢語速）：這張不是我們家的。
音效：雨聲穿過門縫。
```

## 分集組織

分集可套用任何格式，連載預設依集數組織，單部作品按需要分章或分幕。用集首動作帶入現狀，正文呈現目標、阻力、選擇與可見結果，非終局集再用結果引出後續壓力，終局依核准結局完成兌現。前情提要及下集預告僅在作品需要時加入。

## 拍攝、配音與分鏡銜接

- **畫面能執行**：透過動作寫清固定空間、人在哪裡、從哪裡到哪裡、看得到什麼、關鍵物件的材質與狀態。多人、追逐或空間複雜時可另附調度說明，保留正文可讀性。
- **發話能提取**：對白、畫外音、旁白及需要聽見的播報有獨立行與來源定位。手機文字、字幕和系統聲分清看見或聽見。可用場號與發話序號回查鎖稿，已有編號就沿用。
- **配音可表演**：對 AI 配音、TTS 與生成影片，依角色目的安排停頓、重音、尾音、音量、情緒及必要呼吸。用簡短發聲提示和有表演作用的標點；角色之間保留各自說話習慣。已鎖定原句維持原字與標點，替代配音寫法經核准後另立版本。
- **時間能成立**：字數可提示風險，估算要含實際念法、停頓、動作、反應及可並行程度。影片生成交接依 [台詞與時長品管](../../film-quality-control/references/timing-and-dialogue.md)，無試讀或成品時將時間明示為估算。鎖定台詞超時先調整段落或分組，改字需授權。

交接拍攝或影片提示詞時，附必要的劇本版本、可回查發話、關鍵調度與目前時長依據。單純交付劇本時保留本次要求的製作資訊即可。
