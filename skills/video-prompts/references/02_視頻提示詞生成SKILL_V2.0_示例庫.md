# 視頻提示詞生成工作流 V2.0（補充筆記與引用規範）

skill 作者（抖音/B站）：Elio_AIGC

> 本文件為風格基調、音色設定與資產引用的補充說明。具體提示詞結構與主要範例請直接參閱同目錄 `format-example.md`。

## 1. 風格與音色設定指引

- **視覺風格基調**：依專案目標標註客觀風格種子（如寫實電影光影、PBR 3DCG 渲染或手繪 2D 賽璐璐），陳述關鍵視覺特徵即可，避免堆疊無關黑話。
- **角色音色設定**：音色描寫應聚焦於核心聲線質感、語速與表演邊界（如沈穩低音、語速適中、剋制表達），按需提供語音模態引導，不強加固定多維度屬性公式。

## 2. 資產狀態引用與代幣語法

- **語法規範**：資產代幣格式為 `@資產名 `（後方需留半形空格），且僅限引用當前請求實際附加之資產檔案。未綁定素材以客觀文字描述，待補資產於外部筆記註記 pending。
- **靜態狀態區分**：客觀且持續之視覺或形態外觀差異，使用狀態代幣（語法示範：`@資產名_狀態詞 `，如戰損、斷裂等外觀狀態標記）。
- **即時動作與動態情緒**：角色的即時動作、瞬時面部反應與情感波動，應直接寫入主體動作鏈或對白修飾中，禁止混充為靜態資產狀態標籤。
