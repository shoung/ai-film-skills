# 表演控制共通規則：MiniMax H3 / Seedance

<!-- 維護來源：skills/video-prompts/references/performance-control.md -->

本規則適用於人物表演提示詞，涵蓋對白、反應與日常動作。情境需要時提供鏡頭可見動作與動勢。

## 1. 內部思考鏈與提示詞正文
用角色目標、觸發點、停頓與可見反應安排表演。正文只寫推動場景的主幹動作及必要節拍。

## 2. 表演動作與鏡頭可讀性
- **自然動勢**：視線與頭部隨情境自然協調，不設定僵化順序。
- **單一動作鏈**：維持清晰主線（如伸手取物、飲用、放回），避免矛盾多工。
- **直觀運鏡**：使用推近、拉遠、平移、固定等通俗術語，不堆砌焦段數值，不與固定機位矛盾。
- **杜絕微動作填料**：不加入無目的眨眼、抓衣角等瑣碎動作。
- **情緒表現**：強烈情緒需有明確事件觸發，配合可見動作自然流露。

### 關鍵表情

只有當表情對劇情重要，而且當前景別與角度看得清楚時，才使用以下寫法。

1. **寫部位、方向與幅度。** 選一至兩個看得清楚的變化，例如「眉頭微微向眉心靠攏」。需要防止表情被演得過重時，可交代哪個部位維持原狀，例如「嘴角維持原位」。
2. **交代反應何時開始、怎麼收尾。** 依起始狀態、觸發、反應、收尾安排節奏。依劇情讓表情回落、保留一點反應，或在反應途中切鏡。需要時間碼時沿用 0.5 秒網格，並用動作敘述交代表情維持多久。
3. **讓實際首幀對上表演起點。** 圖生影片要拍表情浮現時，選平靜或剛起勢的首幀。要拍表情收回時，選已帶有該表情的首幀，並寫清哪個部位先放鬆。

> 範例｜固定近景，首幀人物神情平靜，雙唇輕合。門外腳步聲停下，她望向門把，上眼瞼微微抬起。停一拍，上眼瞼回到原位，視線留在門把上，切鏡。
