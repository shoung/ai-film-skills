# 新創作啟動 Intake

本文件只用於開始新創作或需要重新定義方向的任務。先讀取使用者本輪提供的描述、既有劇本、專案文件與此前已確認決策；不得把開場問答當成每輪或每階段的固定儀式。

## 先判斷工作類型

- **全新案**：沒有可延續的劇本或已確認專案設定。確認核心概念、媒介／類型與使用者最在意的創作目標；已有答案不重問。
- **已有劇本**：先讀取劇本和相關設定，辨認使用者要診斷、改寫、擴寫或轉成製作文件；保留明確鎖定的內容。
- **續作**：先讀取前作、人物與世界設定及已確認結局；只詢問續作新方向或連續性中真正缺少的決策，不重新訪問前作設定。
- **局部修訂或維護**：依指定段落、檔案或規則直接處理；沒有必要時不啟動創作問答。

## 補問方式

先從已有資訊推斷不影響核心品質的細節。只有缺少的資訊會實質改變方向、結構或可執行性時才提問；每輪最多 2–3 題，先問最重要的，回答後只補剩下的重要缺項。使用者說「你決定」、授權自行判斷或已選定方向的部分，依授權直接作判斷，不再追問；簡短標示重要假設即可。可把合理預設說清楚並繼續處理，不要為了填滿欄位而停工。使用者已決定、前文已回答或素材已明示的事項都視為已知；若新指示與舊決策衝突，只針對該衝突確認。

## 依交付類型挑選問題

下列是可選問題庫，不是每案必填表。只挑出本次交付真正缺少且重要的項目：

- **劇本／故事**：目標與受眾、發布平台、片長或篇幅、現有劇本／素材、要交付大綱或完整劇本、不可改動的設定。
- **視覺資產**：現有劇本與角色／場景／道具素材、正式核定卡與版本、視覺風格、鎖定的外觀或狀態、需要提示詞還是實際圖片。比例／解析度只在會改變實際圖片製作且無法推斷時詢問。
- **分鏡／影片提示詞**：現有劇本與素材、發布平台、目標片長、畫幅比例與解析度、視覺風格和鎖定內容、要交付八欄表或可直接提交的哪種模式 prompt。目標模型只在撰寫模型專用 prompt 而無法由上下文判定時詢問；預算與模型細節只在使用者要求實際生成或製作時詢問。
- **成片製作**：受眾與發布平台、片長、比例／解析度、劇本與正式核定卡版本、風格與不可改內容、交付形式；模型和預算只在需要實際生成時補問。

例如，全新影片案第一輪可合併成 2–3 題：「這是全新案、續作或既有劇本改編？已有劇本、素材或正式核定卡及版本嗎？」、「主要受眾與發布平台是什麼？片長和畫幅有沒有硬限制？」、「這次要交付分鏡表、提示詞還是實際生成的影片？已有必須沿用的風格與不可改內容嗎？」若使用者已說「你決定」，把該選項留給導演判斷；模型與預算不是純文字創作的例行問題。

## 識別標記

全新創作任務在對話中顯示 [SHOUNG 文字標記檔](../assets/shoung-logo.txt) 的完整內容一次，原樣獨立呈現（可用純文字 code block）；不要只憑記憶縮寫或改造檔案內容。續作、新階段、一般交接、局部修改、維護、列清單、安裝與解說不重複顯示。此標記只供對話識別，永遠不得寫進作品正文、模型 prompt、參考圖標註或生成媒體。

## 下游交接

交接時攜帶已決定的方向、版本、鎖定內容、未決事項與指定下一步。下游技能沿用這些決定，不重跑啟動標記或已完成的提問；只有本技能缺少且會影響下游工作的關鍵資訊時才補問。
