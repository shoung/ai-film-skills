# 劇本階段分流與交接

以本輪委託及已有素材判斷從哪裡開始。單場、單點、續寫和製作格式轉換可直接處理。未鎖定的候選、借用假設及已核准設定各自標明。若本輪授權可解決已有衝突，按本輪指示更新相關決策；缺乏授權且實質影響結果時，才確認衝突。

| 階段與已有素材 | 下一個交付 |
| --- | --- |
| S0–S1，靈感或未確認方向 | 依 [啟動訪談](startup-intake.md) 確定本輪目標、方向與邊界。原著改編先取得相關原文證據與候選，再定改編方案。 |
| S2–S3，方向已定或已有大綱 | 用 [劇本框架](../../screenplay-framework/SKILL.md) 建立或補齊專案檔案與人物、世界、調性設定。可先有草案，待核准方向及適用大綱確定後交付正式版本。已有足以支撐寫作的核准綱要和等效資料時直接承接。 |
| S4，綱要與必要設定已定 | 交 [劇本寫作](../../screenplay-writing/SKILL.md) 完成指定範圍的初稿，標清格式、場次或集數、版本與待決項。單純續寫或局部改稿依已有劇本接續。 |
| S5，有劇本、大綱或片段 | 交 [劇本醫生](../../screenplay-doctor/SKILL.md) 診斷指定範圍。全劇會診需要完整劇本；完整大綱可做全案大綱會診。單集、單場、片段或 logline 各按可見材料定範圍。 |
| S6，有會診報告或結構修訂委託 | 將證據與已採納的修改交寫作，修訂後記錄採納、暫緩、未採納與改動範圍。確認前後因果、人物關係和相鄰場或集的承接。 |
| S7，結構基本鎖定 | 交 [台詞專家](../../dialogue-expert/SKILL.md) 做全量診斷。局部試調可以較早進行。改動會影響因果、人物關係或場次時，回到結構修訂。 |
| S8，已有台詞替換清單 | 交寫作整合採納項，確認角色語言一致性與未改範圍。已鎖定台詞的變更須核准後更新鎖稿及受影響的下游版本。 |
| S9，委託最終劇本包 | 以下方模板整合核准材料與版本。劇本、分鏡和各模型提示詞依各自格式交付。 |

只在驗證整套流程時使用縮略示例，標示示例與實際驗過的部分。回退到先前階段時保留已定且仍有效的資訊，說明須更新的成果。

## 交接摘要

切換階段、跨作者交接、暫停待續或需要追蹤進度時，沿用既有專案紀錄填寫下列資料。一般續寫與小修訂可以直接更新既有檔案。

```text
專案與當前階段：
輸入資料、來源位置及版本：
本次新增或修訂成果及版本：
已確認的方向、硬約束與鎖定項：
使用者確認或授權、建議採納狀態：
待決事項、缺件及其影響：
下游負責的範圍與指定下一步：
```

以專案既有版本命名追蹤；沒有約定時可沿用初稿、結構修訂稿、台詞整合稿的版本序。會診的 [修改任務清單](../../screenplay-doctor/references/roundtable-review.md#修改任務清單) 與 [台詞替換清單](../../dialogue-expert/references/dialogue-diagnosis.md#台詞替換清單) 附在交接資料中。單獨安裝時，兩類清單都可用逐項的場次、原文、處理理由、影響與採納狀態交接。

## 最終劇本包

使用核准的劇本原檔或連結，填入委託要求的交付材料。必要資料未到齊時標版本、缺件和暫行狀態。

| 資料 | 內容 |
| --- | --- |
| 專案檔案 | 專案名、作品類型、媒介、受眾、調性與對標狀態。 |
| 最終 logline | 主角、目標、阻力與關鍵利害。 |
| 人物表 | 定位、外形、性格、人物弧線及關係。 |
| 完整劇本 | 核准版本的場次、集數與正文。 |
| 場次表 | 場次、時間、地點、人物、戲劇目的、衝突與轉折。 |
| 場景清單 | 主要、可複用、高成本及待確認場景。 |
| 道具清單 | 必需、劇情或具辨識度的道具，及關鍵狀態。 |
| 服化與視覺提示 | 核准造型、色彩、視覺方向與限制。 |
| 台詞風格表 | 各角色用詞、句長、語氣、口頭禪與禁用詞。 |
| 拍攝或 AI 製作重點 | 空間、走位、道具、表演、剪輯節奏與台詞提取。如需實作，再載入 [視覺資產](../../visual-asset-prompts/SKILL.md) 或 [影片提示詞](../../video-prompts/SKILL.md)。 |
| 版本紀錄 | 專案檔、綱要、劇本、會診、台詞修訂與相關素材版本。 |
| 待確認事項 | 尚未鎖定的創意、素材、製作或 QA 狀態。 |
