# 表演控制共通規則：MiniMax H3 / Seedance

本規則適用於兩種模型的所有人物表演提示詞，包括有臺詞、沉默反應與生活動作。核心是：**不要只寫情緒，要寫鏡頭證據。** 情緒名稱可以輔助理解，但不能代替可見、可聽、具先後因果的表演。

這是表演寫作規範，不是模型官方能力保證。保留劇本、人物關係、場面調度與各模型原有格式；例子是方法示範，不是要求每場照演。

## 1. 必備表演鏈

每個以人物表演為主的鏡頭或連續段落，先建立以下六項，再把必要資訊寫進原有 prompt 欄位，不另輸出一張心理分析表：

1. **角色目標**：此刻想讓誰做什麼、阻止什麼、掩飾什麼，或在確認什麼。讓目標落成正在執行的行動，例如伸手攔住離開的人、收回碰向物件的手，而非只寫「想挽留」「內心矛盾」。
2. **起點與轉變**：從哪種可見狀態，經由什麼刺激，變成哪種可見狀態。先保持、再動搖或收束；不要一出場就演到最強，也不要求每鏡都有完整情緒大轉折。
3. **精確觸發點**：指定聽見誰的哪個字／短語才反應，保留原臺詞。沒有臺詞時，指定已在場景中的事件，例如「門扣響後」「鞋尖碰到水後」「看清對方的臉後」；不要只寫「突然」「這時」或捏造一句臺詞當觸發。純持續行為可由片段起點的既定動作觸發。
4. **呼吸與停頓**：寫可感的時序，例如吸氣中途停半拍、閉口停住一拍、慢慢呼出；留出實際片長。不是每句都吞嚥、喘氣或抽泣，呼吸也可以一直平穩。
5. **可見證據**：選景別能看清的眼瞼、嘴角、下頜、肩或手指變化，寫方向、幅度、順序。每一節拍只保留少量有效線索，讓反應隨觸發逐步長出來，不在同一瞬間塞滿所有部位。
6. **落點與禁止提前的反應**：交代這一拍結束時視線、手和身體停在哪裡，承接下一拍。明說關鍵觸發前仍保持什麼、尚不做什麼，例如「聽完關鍵字前，伸出的手不收回，嘴角尚未落下」。

可用的句法是：**維持原狀／正在做的事 → 明確觸發 → 短暫停頓與呼吸 → 一兩個可見變化 → 下一動作或停留。** 若跨鏡，延續前鏡已到達的狀態，不重新演一次反應。

## 2. 眼神與微動作的可讀性

- **轉移注意力時，眼神先走，頭部再跟**：先寫原本看哪裡、新目標在哪裡，以及視線短暫停留，再讓頭慢慢轉到同一方向。人物本來已看著目標時，不硬加一次轉頭。
- 「眼神閃爍」「瞳孔輕微顫抖」改為鏡頭可辨的視線短暫偏移、重新定焦、眨眼或眼瞼細動。不要要求瞳孔自行抖動、劇烈縮放或不合理的眼球震顫。
- 克制的笑可寫嘴角少量上揚、眼瞼稍收窄、停留後保留餘笑；不自動變成露齒大笑、用力瞇眼或誇張挑眉。
- 收緊下頜、抿住嘴唇、肩膀下沉、手指停止摩挲，都需有當下原因與幅度。不讓每個部位同時顫抖，也不把每個線索拆成獨立鏡頭。
- 一次生活動作維持一條動作線：抬手 → 將髮絲撥至耳後 → 手自然落回；肩膀放鬆，不連續重撥、不擺拍、不在手仍佔用時讓它同時握住其他物件。
- 近景可用眼瞼與嘴角；全景改用停步、重心、肩手或距離。不可為了看見微表情而改動已鎖定的景別，也不在遠景宣稱能看清淚珠或細小唇顫。
- 人物的自然微動、環境震動與運鏡分開寫。車內若只有懸吊造成的輕微起伏，就寫被動微晃；不要誤變成演員反覆搖晃或強烈手持震動。

## 3. 節拍示例

以下為內容示意，實際交付須套回目標模型的語言、欄位、資產引用及時間格式。只採用劇本需要、片長容得下的節拍。

### 對話觸發：挽留受到動搖

不能只寫：「她難過地看著他，生氣地說。」

可寫：她原本朝對方伸出手，掌心仍開著，試著攔下離開的動作，呼吸平穩。對方說「我不會再回來。」；直到「不會」說完，她的手指才停住，吸氣短暫中斷。句末停半拍，嘴唇抿緊、下頜略收，手慢慢落下，目光仍留在對方臉上。關鍵字前不先收手，不提前落淚。

劇本若要求怒意，讓它由被打斷的動作、收緊的下頜、說話前的吸氣與特定字的力度呈現；不是直接升成吼叫。說話者、聽者分開寫，避免把反應放錯人。

### 生活動作：發現鏡頭、含笑撥髮、再看窗外

她原本望著巴士窗外的草坡與海岸。察覺鏡頭正對著自己後，視線先從窗外移向鏡頭，頭部稍後慢慢跟上；短暫對視，眼瞼稍收窄，嘴角出現不露齒的輕笑。她稍低下巴，移開視線，右手順勢把臉側髮絲撥到耳後，整個動作只做一次，肩膀放鬆、呼吸平穩。手落下後，再抬眼看鏡頭一拍，保留餘笑；接著視線先轉向畫面左側的窗外，頭部才跟回去，左手仍放在窗邊。身體僅隨巴士懸吊輕微起伏，不額外搖晃。

目標是被注意後短暫回應、恢復原本的觀看。沒有悲傷、眼紅或流淚的劇情依據時，不把這個生活動作改成哭戲。

### 哭戲：只有劇本確實需要時才選用

眼紅、積淚、落淚不是所有情緒的通用結尾，也不是每次悲傷都必須出現。各序列的情緒名稱只是導演理解的提示；輸出仍靠鏡頭證據。給積淚與反應足夠時間，不在一瞬間切換所有生理狀態。

- **心碎的安靜反應**：聽到確定失去對方的句尾後，慢慢抬眼，目光短暫停住，眼瞼微動；停留、呼吸放慢，眼眶逐漸積淚，最後才有一滴沿臉頰滑下。觸發前不先哭。
- **思念但想維持平靜**：望著窗外的目光暫時失去定點，低頭，再抬眼；抿住嘴唇，眨一次眼試著含住已積起的淚，鼻翼隨吸氣略收緊，最後才有淚落下。眼紅只在劇本與可見時間進程支持時出現。
- **防備轉為自責、逐漸失守**：觸發前抬眼防備，下頜繃住；聽完關鍵內容後，凝視放鬆、低頭壓住呼吸，嘴唇只輕微顫一下。再次抬頭時才容許積淚滑落；若原劇本有臺詞，保留原句，以短停頓和被呼吸打斷的低聲呈現哽咽，不加哭喊或額外告白。

上述哭戲的外部觸發必須來自當前劇本。不能把「失去」「思念」「自責」當成可直接拍到的畫面，也不能為套例子新增人物身世或情節。

## 4. 寫回模型原有格式

### Seedance

- 保留 `畫面 → 鏡頭 → 運鏡 → 動作 → 臺詞 → 光線` 六欄與原組約束，不新增「角色目標」「表演分析」等欄位。
- 角色目標以動作策略落地；身體、手、肩、姿態和物理／聲音觸發放入 `動作`；原臺詞、精確字詞觸發、停頓與臉部反應放入 `臺詞`，跨欄時讓兩者的先後因果一致。
- 無臺詞仍可寫 `臺詞：無。`，後接必要的沉默、視線與臉部反應；不為建立觸發點捏造臺詞。
- 延續主流程的降噪限制：每鏡最多三個身體／姿態錨點，面部線索優先一至兩個，保留一個最重要的節奏重點。示例長序列可依劇情分配到連續段落，不把所有線索塞進同一短鏡。
- 「不提前反應」直接附在該動作／臺詞節拍中；不為此改動固定組約束或增設風險清單。

### MiniMax H3

- T2VA / I2VA / FL2VA / L2VA 的表演鏈融入 `integrated_multimodal_description`；Ref2VA 融入 `detailed_description`。不新增頂層表演欄位。
- 保持選定指南要求的英文敘述、原語言臺詞／歌詞／畫面文字、speaker ID、參考標籤、時間碼與關鍵影格對齊規則。
- 所有動作、呼吸、停頓與反應指令放在 `<d>` 外；不要把導演指令變成角色唸出的臺詞，也不因標示聽者而替完全不發聲的人新增 speaker ID。
- 正文寫清聲音觸發與身體反應的同步點；`overall_soundscape` 只總結環境及非語言聲音，不重複整句對白；`non_diegetic_music` 不承擔人物表演控制。
- 參考圖或首尾幀已鎖定姿態時，讓表演沿可行路徑銜接，不能為套微動作而違反關鍵影格、手部佔用或道具連戲。

## 5. 輸出前核對

- 能從動作看出角色此刻在做什麼、企圖達成什麼嗎？
- 起始狀態、明確觸發、反應順序與落點是否一致？臺詞中的哪個字，或哪個無臺詞事件，啟動了變化？
- 觸發前的保留狀態與不能提前的反應是否寫清？是否錯把下一鏡才發生的情緒或動作提前？
- 呼吸／停頓有時間，表演不靠抽象標籤，線索在目前景別可見嗎？
- 注意力轉移是否眼先頭後？手勢是否一次自然完成並有返回位置？
- 是否去除瞳孔抖動、全身同時顫抖、機械重複、無劇情根據的眼紅／眼淚，以及過量微表情？
- 是否保留模型格式、原臺詞、資產與關鍵影格限制，沒有為表演補寫新情節？
