# 原生專案讀取契約

創作台以本套件現有技能輸出為主，不要求把原文改寫成 drama-skills 的 EP／SC／SHOT／MOTION 格式；後者仍作兼容輸入。所有結構視圖都可回查原文，不建立第二套創作真源。

| 文件 | 本套件結構 |
|---|---|
| 劇本 | `1-1 場景名 日 內`；可用 Markdown 標題及 `／` 分隔，時間碼可附於標題後。一般說明如「本版鎖定」不是場次；人物行、動作、說話者與括號提示保留。 |
| 視覺資產 | 角色／場景／道具類別下的 `### @資產名`，以及 `#### @資產名_狀態`；保留父子關係與文生圖提示詞。 |
| 分鏡 | 固定八欄、每鏡一列；讀取 Markdown、CSV，兼容舊版多「修改」欄的表格。附註不成為第九欄。 |
| 影片提示詞 | 依鏡號或生成群組的獨立請求，可分多檔；H3 三個核心欄位、JSON／文字區塊及 Seedance 提示詞正文維持原文。一份多鏡請求仍只是一份請求。 |
| 圖片提示詞 | `@` 狀態資產、單幀或圖像段落的實際提示詞；區分生圖正文與素材／後製說明。 |

## 主表與其他輸出

同一份表同時有 MD／CSV 時，比較解析後的內容；`<br>`、CSV 儲存格換行及跳脫表示不當作內容衝突。使用入口中的 `[分鏡主表](相對路徑)` 明示主要來源，其他副本保留對照，不能自動把不同來源的文字拼成新版本。

沒有明確主表且實質內容不同時，只呈現一次分集摘要，逐鏡可查看差異欄位。多個主表宣告、同檔重複鏡號、鏡號缺失或多出仍須提示；不同版本／不同集不能互相覆蓋。解析成功的原生文件不再送入上游格式解析器產生假錯誤。

## 剪輯單是選用的後製旁表

分鏡表描述計畫；生成提示詞描述一次生成請求；剪輯旁表描述實際採用哪些檔案、取用區間及如何組裝成片。三者不同，八欄不增加剪輯欄。

只有需要終剪方案、素材取捨、入出點、字幕／畫面文字、配音／音效落點或交付規格時，才按需建立剪輯旁表。單純瀏覽影片素材不需要剪輯單，也不應被提示成缺少必交文件。有剪輯資料時可顯示時間線；沒有時顯示實際素材候選，不假造剪輯決策或正式成片。

來源差異、素材候選、剪輯選用與 QA 通過是不同狀態。介面不批准審查，保存或讀取成功不代表獨立 QA 通過。
