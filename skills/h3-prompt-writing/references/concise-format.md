# 精簡生成提示詞格式

本規範優先於舊指南中衝突的格式、時間精度與篇幅要求。這是本 skill 的預設交付格式；使用者明確要求的語言、鎖定區域、精度及已驗證的模型介面限制優先。

## 刪減與換行

- 只輸出生成必需的內容：人物／素材引用、構圖與機位、動作因果、聲音／臺詞及必要的狀態連續性。
- 不預設附逐鏡幀表、全片絕對時間碼、成片採用區、可刪頭尾餘量、逐字驗算、重複組名、官方規格介紹或通用防錯清單。使用者要剪輯交付時，另存時間表，勿混入可貼用正文。
- 保留必要的素材綁定；不能為求短而令圖片、人物或說話者引用無定義。全局聲音／風格只寫一次；每次獨立提交仍須附實際需要的共同設定，不假設模型記住前次。
- 「當下行動目標：」「觸發：」各自獨立一行，每個「起秒–迄秒：內容」亦獨立一行。需要防止特定錯誤時才加一行「不得提前：」，不重述整段動作。
- 場景沒有主動人物時用「場景進程：」，不要硬造人物目標。構圖不見臉時不添加眼口微表情。
- 多個階段屬同一長鏡時，以秒數換行，不能為了格式拆成多個鏡頭。

## 段內鏡號

- 每個獨立 prompt 自鏡頭1／[Shot 1] 起算。同組回指用該組實際編號；真正承接上一鏡才寫上一鏡。
- 原分鏡表的序號只可留在外部段落標題或對照索引，不進入生成正文的動作、觸發、臺詞或切鏡敘述。
- 跨組引用改寫成具體承接狀態，例如「手已鬆開物件」，不要引用未隨請求提交的鏡號，也不要把任何舊鏡號機械換成「鏡頭1」。
- 同一長鏡內說「本鏡前段／後段」，不把自己的鏡號誤寫成前一鏡。

## 秒數

- 敘事時間預設以 **0.5秒** 為最小單位：0、0.5、1、1.5……；不產出1.3、0.666667或毫秒式切點。
- 先對每個必要動作區間長度做 `ceil(時長 / 0.5) × 0.5`，再由0累加切點；不能僅對既有起迄點各自進位而縮短其中一段。
- 修訂時每鏡、每個必要動作區間及整段總長均不可比原稿短。允許延長，保留合理呼吸與既有動勢收束，不靠慢動作、重演或新增事件湊秒。
- 模型請求總時長與鏡內敘事秒數分開：若已驗證介面只收整秒，請求總長再向上取整，鏡內仍用0.5秒；這不是宣稱所有平台通用限制。
- 若超過已驗證模型上限，在合理切點分段；無切鏡長鏡不得任意拆鏡。必要時詢問取捨，不縮短動作硬塞。
- 時間更動後同步檢查臺詞、切鏡、聲音與反應描述；有舊幀表時明示失效或另行更新，不宣稱未更新的文件仍一致。
- 使用者鎖定的段落逐字保留，即使含舊精度或格式；不可藉套用全局規則順手更動。

## 驗收

檢查每段從0開始、區間連續不重疊、所有內容在該鏡起迄內、時間均為0.5的倍數、總長不縮短、回指編號存在且語意正確、原臺詞逐字保留、參考標籤可解析。檢查受保護內容未變。只報告實際完成的檢查。

## 範例的邊界

同目錄的短範例從已修訂文件抽取結構，替換情境後只示範格式。不得繼承範例的故事、角色數、場景、道具、畫幅、片長、色調、天氣或臺詞。正式生成必須重新讀取當次劇本與素材。
