# H3 全參考模式提示詞撰寫指南 (Ref2VA / Full-Reference Mode)

> 來源規範：H3 Video Prompt Writing Guide (Full-Reference Rewrite)。本指南規範全參考模式之六大核心區塊、資產引用標籤與保留分析。
> 實務範例與精簡指引：請參閱同目錄 `concise-format.md`、`performance-control.md` 與 `format-example.md`。

## 1. 核心結構與六大區塊順序

全參考模式（Ref2VA）輸出必須嚴格依序包含以下六個區塊。區塊鍵名維持英文 literal，正文描述使用繁體中文（`<d>` 內對白與畫面可見文字保留原文）：

| 區塊名稱 | 功能說明 |
|---|---|
| `subject_definitions:` | 定義引用資產與其對應標籤（角色、物件、場景、影片結構、音訊） |
| `summary:` | 以短段落摘要任務類型前綴（如 `[reference generation]`）、目標影片與主要引用關係 |
| `retention_analysis:` | 逐項分析引用資產在目標影片中的保留、轉移或複用程度 |
| `detailed_description:` | 開頭以 1–2 句確立風格，隨後依時間軸按鏡頭描述畫面、動作鏈、運鏡、發聲主體與引用落點 |
| `overall_soundscape:` | 總結全片背景環境音與物理音效 |
| `non_diegetic_music:` | 描述觀眾側專用背景音樂（風格、樂器、節奏、動態） |

## 2. 引用標籤與定義規則 (`subject_definitions:`)

嚴格區分視覺主體、影像錨點、影片結構與音訊資產：
- `<Subject N>`：可複用或修改的具體視覺主體（人物、動物、物件、場景、服裝、風格）。多個參考資產可共同定義同一個 `<Subject N>`，單一資產亦可提供多個 `<Subject N>`。定義句可自然使用 `is` 或 `：`，亦允許在定義中進行語意內聯說明（如指出外貌來自 `<Picture 1>`、動作來自 `<Video 1>`）。
- `<Picture N>`：作為畫面具體錨點（首幀、關鍵幀、尾幀或構圖分鏡錨點）的參考圖片。若僅作為角色或場景特徵參考，應直接整合於 `<Subject N>` 定義中，無須建立獨立 `<Picture N>` 項目。
- `<Video N>`：提供整體時間結構、剪輯來源、銜接起點或運鏡節奏的參考影片。影片中的具體人事物若被複用，仍歸入 `<Subject N>`。
- `<Audio N>`：複製或引用的音訊資產（音色參考、BGM 或原聲音軌）。視覺與音訊軌道角色獨立且編號各自獨立；同一參考影片包含聲音不自動成為 `<Audio N>`，僅在明確引用時建立。當 `<Audio N>` 明確綁定至目標影片說話者時，直接複用該角色於全片的說話者編號 `<Subject N> (Sx)`，不可獨立分配新編號。

## 3. 任務類型前綴 (`summary:`)

摘要段落以中括號任務前綴開頭，多項任務以 ` + ` 連結，不得重複：
- `[keyframe completion]`：圖片作為首幀、尾幀、關鍵幀等具體畫面錨點。
- `[reference generation]`：資產提供角色、場景、風格、動作或運鏡參考，非具體幀錨點且非剪輯主體。
- `[video editing]`：直接修改現有來源影片（首句固定接：`The target video is an edited version of <Video 1>.`）。
- `[video continuation]`：從既有影片延續、接續新內容。
- `[audio reuse]`：直接 1:1 完整複用或部分複用音訊訊號。
- `[audio reference]`：不複製原始訊號，僅參考音色、語氣、曲風、節奏或聲音質感。

## 4. 保留關係分析標記 (`retention_analysis:`)

每個定義的引用標籤必須獨立一行分析，嚴格使用以下原始固定英文標記：

### 4.1 視覺與影片結構標記 (`<Subject N>`, `<Picture N>`, `<Video N>`)
- `fully_preserved`：完全保留設定特徵或定義功能。
- `partially_preserved`：部分保留特徵，部分屬性有所修改。
- `attribute_transfer`：將參考特徵轉移至另一可識別主體。
- `weak_reference`：僅保留廣泛風格、氛圍、類別或大致構圖。

### 4.2 音訊標記 (`<Audio N>`)
- `fully_copy`：來源音訊完整 1:1 複用為目標影片之完整最終音軌。
- `partially_copy`：僅複製部分時間線、特定音軌層，或複製後增刪、替換其他聲音層。
- `reference`：不直接複製訊號，僅參考音色、語氣節奏、曲風或聲音質感。
- `weak_reference`：僅保留氛圍或類型相似性。

> 注意：`retention_analysis:` 中禁止標註 `(Sx)` 說話者標籤。

## 5. 詳細描述與音訊規範 (`detailed_description:`)

1. **結構差異與風格開頭**：在 `detailed_description:` 開頭以 1–2 句繁體中文陳述全片風格（在 `[Shot 1]` 之前）。移除機械式 350–500 字配額，依情節與資訊密度精簡描述，不強加微動作填料。
2. **切鏡與時間軸**：`[Shot 1]` 開頭不帶時間戳；後續切鏡採用遞增時間戳 `[Shot N] At MM:SS.mmm, 鏡頭切至...`。切鏡語法與規範請參閱 [base-en.txt](base-en.txt)。Ref2VA 之身分與場景參考可支援多鏡頭連續敘事。
3. **說話者與對白**：
   - 說話者編號、實際發聲順序、複合群組編號 `(S1,S2)`、對白 `<d>` 與旁白固定片語語法，與 [base-en.txt](base-en.txt) 共用相同規範。
   - 角色實體發聲標註 `<Subject N> (Sx)`。若為純畫外音旁白，必須使用固定片語 `says in an off-screen voiceover:`，且其後緊接描述畫面中對應角色雙唇保持緊閉（如 `while his lips remain completely closed.`）；畫外音仍具備穩定的 `(Sx)` 說話者標籤。
   - BGM 純音訊例外：若為直接複用之 BGM 或完整音軌中自帶之聲音，僅在完全沒有獨立人類／角色／旁白聲音來源實際發聲時，方標註為 `<Audio N>`，而非單純「畫面上無實體人物」。嚴禁虛構 `(Sx)` 或設立獨立 `MUSIC` 說話者。
   - 對白鎖定：`<d>[語言標籤] 原文對白</d>` 精確保留原文字句與標點；聽不清處標註 `[unclear]`；跨鏡頭使用 `<scenetrans>`，截斷使用 `<cutoff>`。
4. **請求獨立與起始狀態**：每個生成請求皆為自洽之獨立單元。分鏡表維持八欄標準結構，每行對應一個連續鏡頭。分組應依因果、節奏、介面能力與重試成本審慎判斷。僅有實際提交之資產具備錨定效力，身分卡無法提供前置時間狀態，每請求必須明確建立起始狀態。內部 QA 與製作筆記嚴禁放入提示詞。範例均為合成格式示意，禁止偽造 PASS。

## 6. 音景與非劇情配樂 (`overall_soundscape:` / `non_diegetic_music:`)

- `overall_soundscape:`：總結環境背景音、物理碰撞與非語言人聲。若複用 `<Audio N>` 之環境音層，在此處說明。
- `non_diegetic_music:`：觀眾側背景配樂，著重樂器、速度與動態變化。若複用 `<Audio N>` 之配樂層，在此處說明。
