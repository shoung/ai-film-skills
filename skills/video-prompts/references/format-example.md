# 精簡提示詞格式範例

此例節錄實際修訂稿的「段落標題、段內鏡號、六欄、行動目標、觸發、秒數換行」結構，已縮短並替換人物、場景、道具與事件。只學格式，不作任何新專案的劇情預設。素材示意：@人物甲、@物件甲；實際使用前綁定本次素材。

## A01｜收妥物件

生成：6秒；

```text
劇情：人物甲拿起桌上物件，放入抽屜。
環境：室內工作桌；
光：窗邊柔光；
聲：衣料與木質接觸聲。

鏡頭1（0-3秒）
畫面：側面平視中景機位，@人物甲 的手、@物件甲 與桌緣同框。
鏡頭：50mm，中景深，焦點落在手與物件。
運鏡：固定。
動作：人物甲確認物件位置，握穩後提起。
當下行動目標：穩定拿起物件；
觸發：手指碰到物件兩側。
0–0.5秒：視線落向物件；
0.5–1.5秒：手指貼住兩側並握穩；
1.5–3秒：提起物件，保持水平。
臺詞：無。
光線：柔光沿手背與物件側邊延續。

鏡頭2（3-6秒）
畫面：桌側略高機位近景，手中物件與打開的抽屜同框。
鏡頭：65mm，中淺景深，接觸面清楚。
運鏡：固定。
動作：承接鏡頭1已提起的物件，人物甲將它放入抽屜。
當下行動目標：讓物件落穩後才鬆手；
觸發：物件底部接觸抽屜內面。
3–4.5秒：持物件下降；
4.5–5秒：物件落穩，手指鬆開；
5–5.5秒：說「好了。」；
5.5–6秒：手退出抽屜，保留自然呼吸。
臺詞：人物甲：「好了。」平聲短句，不加其他口白。
光線：抽屜內保留可讀暗部。

約束：有音效，無音樂，無字幕。
```

時間示例：原三個動作分別0.3、0.8、1.1秒，應改成0.5、1、1.5秒，累加成0–0.5、0.5–1.5、1.5–3秒。不要把原切點分別進位而壓縮中間動作。跨請求則寫「物件已提起」，不引用另一組的鏡號。
