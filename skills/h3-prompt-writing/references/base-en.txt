# H3 基礎模式提示詞撰寫指南 (T2VA / I2VA / FL2VA / L2VA)

> 來源規範：H3 Video Prompt Writing Guide。本指南規範基礎模式之提示詞結構、鏡頭語法與生成請求邊界。
> 實務範例與精簡指引：請參閱同目錄 `concise-format.md`、`performance-control.md` 與 `format-example.md`。

## 1. 任務概述與模式定位

- **T2VA (Text-to-Video-Audio)**：由文字建構完整視聽時間軸，支援單鏡頭或多鏡頭連續敘事。
- **I2VA (Image-to-Video-Audio)**：首幀對齊指令 + 從 `<Picture 1>` 起始向前發展的單一連續鏡頭。
- **FL2VA (First-and-Last-Frame-to-Video-Audio)**：首尾幀對齊指令 + 連接 `<Picture 1>` 與 `<Picture 2>` 之間的連續動態軌跡。
- **L2VA (Last-Frame-to-Video-Audio)**：尾幀對齊指令 + 從合理前置狀態收斂至 `<Picture 1>` 終止畫面的單一連續鏡頭。

## 2. 生成請求獨立性、分組原則與工作流邊界

1. **生成請求為基本組織單元**：每個提示詞請求皆為獨立的生成與控制單元，單一請求可包含單個或多個鏡頭。分鏡表（Storyboard）維持八欄標準結構，每行對應一個連續鏡頭。
2. **審慎分組決策**：鏡頭分組應依據敘事因果、情節節奏、時長可行性、模型與介面之驗證能力、資產依賴清晰度，以及控制與重試成本進行合理決策，嚴禁機械式「一鏡一請求」或無條件「同場景必合併」。若拆分可顯著降低重試成本或避免狀態污染，應獨立發起請求；蒙太奇或強因果關聯鏡頭則可合併。
3. **關鍵幀單鏡頭策略為工作流政策**：I2VA、FL2VA 與 L2VA 採用單一連續鏡頭策略（固定標記為 `[Shot 1]`），為內部確保生成穩定度與控制成本的工作流控管政策，非模型底層能力之上限宣稱。若需多視角切鏡，應拆分為單鏡頭請求後剪輯，或改採 T2VA / Ref2VA（Ref2VA 的身分與場景參考可支援多鏡頭連續敘事）。
4. **請求自洽與起始狀態**：每個請求必須自洽。僅有實際提交的參考資產具備錨定效力；身分卡或道具卡無法提供前置時間狀態。除實際提交首幀或接續幀外，每個請求必須明確陳述起始狀態。外部全域設定不會自動繼承。
5. **製作業務與路由規範**：提示詞撰寫與實質修改優先由 Antigravity 執行；僅在缺少 CLI 或確認配額耗盡時由 Codex 備援介入，或因內容過濾器明確拒絕時由當前預設 LLM 接替（認證、網路、頻率限制、逾時或權限錯誤應直接阻擋，不得作為觸發備援之依據）。Codex 可負責編排、程式碼與審查。在原生 Antigravity 環境中無須遞迴路由。所有製作筆記、QA 記錄與提供商資訊嚴禁放入可複製之提示詞中；禁止偽造 PASS 記錄。指南內範例均為合成格式示意，非真實生成驗收。

## 3. 提示詞結構與第一行對齊模板

提示詞由兩部分構成：第一行為關鍵幀對齊指令（T2VA 無），空一行後緊接三大核心欄位。`S.SS` 代表目標影片之有效時長（嚴格精確至小數點後兩位，如 `8.00` 秒）。

### 3.1 關鍵幀對齊指令模板
- **I2VA**：
```text
For the target video, at 0.00 seconds into the target video, <Picture 1> (from [Shot 1]) is fully referenced.
```
- **FL2VA**：
```text
How the reference pictures align with the target video — Picture 1 (from Shot 1) aligns with the 0.00-second mark of the target video; Picture 2 (from Shot 1) aligns with the S.SS-second mark of the target video.
```
- **L2VA**：
```text
How the reference pictures align with the target video — <Picture 1> (from [Shot 1]) aligns with the S.SS-second mark of the target video.
```

### 3.2 三大核心欄位

```text
integrated_multimodal_description: [Shot 1] ...

overall_soundscape: ...

non_diegetic_music: ...
```

- **integrated_multimodal_description**：描述畫面構圖、主體外觀、動作鏈、運鏡、發聲主體與原樣對白。
- **overall_soundscape**：總結背景環境聲、物理動作音效與非語言人聲（如喘息、腳步聲）。若全片靜音填 `N/A`。
- **non_diegetic_music**：描述僅觀眾可聞的畫外配樂（樂器、節奏與動態）。無配樂填 `N/A`。

## 4. 鏡頭語言與語法規則

1. **語言與用詞規範**：正文描述、動作鏈與音訊描述使用繁體中文（或使用者指定語言）；欄位鍵名、控制語法、鏡頭標籤與指定固定片語維持精確英文。
2. **切鏡與時間標記**：
   - 首個鏡頭 `[Shot 1]` 不帶時間戳。
   - 多鏡頭模式（T2VA / Ref2VA）後續切鏡採用遞增時間戳，格式如 `[Shot 2] At 00:03.500, 鏡頭切至...`（時間標記可按 0.5 秒倍數規劃，普通切鏡使用「鏡頭切至」等繁體中文描述）。
   - I2VA、FL2VA、L2VA 嚴禁語意切鏡、反打或蒙太奇，不可於正文中偽裝多鏡頭。
3. **運鏡表達**：運鏡融入自然敘事中（運動類型 + 幅度 + 速度，如「攝影機以慢速小幅度推進」），避免堆砌術語或強加毫米焦段（如 35mm），去除可選的英文運鏡括號。
4. **說話者與對白規範**：
   - 說話者標記使用穩定編號 `(S1)`、`(S2)`，依實際發聲順序編號；多人合唱或同時發聲使用複合編號 `(S1,S2)`。禁止設立獨立的 `MUSIC` 說話者。未發聲角色不給予說話者編號。
   - 對白使用 `<d>[語言標籤] 原文對白</d>`，鎖定原始對白內容與標點，禁止意譯或擅改。
   - **旁白與嘴部閉合（Voiceover）**：旁白必須使用固定片語 `says in an off-screen voiceover:`，且在每個旁白 `<d>` 區塊之後，必須緊接陳述畫面中對應角色雙唇保持緊閉（例如：`while his lips remain completely closed.`）。
   - **跨鏡頭與截斷對白**：對白跨越切鏡時，兩端銜接點均須標註 `<scenetrans>` 並敘述音訊無縫延續（如 `continues seamlessly across the cut`）；影片結束截斷之語音使用 `<cutoff>`。
   - **畫面可見文字**：招牌、標籤、螢幕文字以英文雙引號 `"..."` 精確標示原文。
5. **精簡原則**：去除強加的微動作填料（microbeats filler），不設機械式字數門檻，聚焦推動情節的主動作鏈。
