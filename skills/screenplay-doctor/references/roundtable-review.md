# 圓桌會診

## 確定範圍與證據

| 委託 | 診斷方法 |
| --- | --- |
| 全劇 | 用完整劇本查結構、人物弧線、調性、節奏及製作條件。 |
| 大綱 | 用大綱檢查事件、選擇與後果。結論標大綱會診，演出或實際對白可留待驗。 |
| 單集 | 查本集因果、局部兌現以及前後集承接。缺相鄰集正文時依可取得的綱要標待驗。 |
| 單場或片段 | 找本場目的、角色變化、場內節拍、台詞和可拍性。從可見片段定位，避免把未知前因寫成缺失。 |
| 單點 | 只查指定問題。logline 或簡短梗概可檢查敘事承諾、主角目標及受眾理解等可由當前資料回答的部分。 |

讀使用者指定的稿、範圍與可取得的專案設定。缺少專案檔時，可先從稿件列出可見的類型、主要角色與初步受眾假設，標明哪些是推論。只有資料或授權不足且會改變結論時才補問。有已核准的對標資料時，可追查適用的創作規律和偏離的實際影響。需要補完整大綱時交 [劇本框架](../../screenplay-framework/SKILL.md)，單獨安裝則先用現有內容完成可以回答的部分。

自然語言與既有指令均可，例如 `會診 第3集`、`會診 單點="主角的選擇成立嗎"`、`會診 評委=[商業製片,責任編輯]`、`+極端`、`/換評委` 或 `/導出歸納`。使用者已選擇範圍或視角時直接採用。責任編輯等名稱用以指出分析角度，無須模擬履歷、固定口吻或印出開場名冊。

## 按問題選視角

| 視角 | 檢查內容 |
| --- | --- |
| 類型編劇、責任編輯 | 結構、節拍、因果、角色弧線及類型期待。 |
| 製片、採購、發行或行銷 | 資源需求、製作限制、發行場景、受眾契合和可傳達的賣點。 |
| 核心受眾、初看觀眾、追劇讀者或二刷觀眾 | 讀者能否理解、本集兌現、跨集期待、伏筆與重看價值。 |
| 演員或影像視角 | 角色是否有可表演的選擇、對白能否成立、動作與空間是否可見。 |
| 合規或權利視角 | 從可查的已知要求評估授權、備案、分級或合規疑點。不確定處列待核。 |
| 反例視角（委託要求時） | 對重要假設提出最強反例，指出在哪個場或條件下可能失靈。 |

既有角色名稱可映射到相應專業視角。全劇按主要問題選足夠互補的角度，單場或單點縮小範圍。寫作者要得到可執行的改動目標，評估者需要看清立項條件和風險，學習者重在解釋手法與效果。報告以委託所需深度為準。

## 形成會診報告

每項發現交代場次／集數、原句或可回查的場上事實、該視角的判斷與影響。區分可直接證明的矛盾、合理推論、口味選擇和尚待驗證的製作假設。不同視角意見相同時合併依據；有分歧時保留來源、依據和要由作者決定的取捨。

按影響分類為「必改、建議、可議、別動」。影響因果、理解或已鎖定前提的實質問題優先。單一視角握有具體證據也可列高優先級。同一模型的多視角一致屬會診觀察，獨立冷讀須有確實未先看解說及結論的讀者。對市場或製作問題給出可行條件、影響與需查證資料。

### 修改任務清單

需要交付修訂或交下游時，將會診結果編成可執行任務：

| 優先級 | 問題與證據位置 | 修改目標及影響範圍 | 保留內容與鎖定項 | 採納狀態與複查 |
| --- | --- | --- | --- | --- |
| 必改／建議／可議／別動 | 場次、原文或大綱節點、相關視角 | 寫甚麼應在何處可被觀眾看見或聽見 | 列不可改動的場次、關係、台詞或設定 | 待決／採納／暫緩，附可核對條件 |

會診交建議與可複查目標。實際改寫由 [劇本寫作](../../screenplay-writing/SKILL.md) 按採納或授權執行。
