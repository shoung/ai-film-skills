# 影視分鏡方法庫 (Storyboard Methods)

本方法庫為 AI 影視製作之分鏡調度指南。文中所述規範為成熟工程實務之推薦預設，旨在保障分鏡結構嚴謹與模型生成穩定，非抹煞創意之審美鐵律。

## 1. 八欄標準結構與填寫規範

分鏡表嚴格維持標準八欄名稱與順序，每列僅記錄一個**連續鏡頭**（Continuous Shot）：

| 欄位名稱 | 填寫重點與語法規範 |
| :--- | :--- |
| **編號** | 鏡頭唯一識別碼（如 `01`, `02`, `02a`）。每列一鏡，不可多鏡混寫。 |
| **畫面描述** | 依本鏡需要交代起點、主動作與終點，避免將完成態提前寫入起態。 |
| **攝影機描述** | 記錄景別（特寫/近景/中景/全景/遠景）、運鏡（推/拉/搖/移/升降/跟/定）與觀看方向。 |
| **聲音描述** | 環境音（Ambient）、音效（SFX/Foley），未知畫外音不得提早揭曉身分。 |
| **旁白對白** | 角色台詞或旁白（註明說話者、情緒與畫內/畫外 O.S.），跨鏡對白不重複填寫。 |
| **時長** | 依既有八欄規範填秒數數值（如 `3`、`4.5`）；未知填「待定」。 |
| **影片生成方式** | 指定生成技術（如 `T2VA`, `I2VA`, `FL2VA`, `L2VA`, `Ref2VA`）。 |
| **畫面prompt** | 短畫面／首幀試作提示詞或既有內容；完整模型專用影音請求另行組織，不取代既有八欄定義。 |

> [!IMPORTANT]
> **劇本覆蓋原則**：劇本中的每個場次均須在分鏡表中具體對應。若劇本有場次未拍攝、合併或刪除，必須於表外明確注明未拍原因，不得無故遺漏。

## 2. 鏡頭拆分與生成單元 (Generation)

* **拆招與切鏡**：拆招動作只拆分實際需要切換鏡頭（Cut）之節點。單一連續動作即使包含多個攻防微動作，只要在同一個連續鏡頭內完成，即維持同一列。
* **生成映射**：一個生成單元（Generation）可涵蓋多列連續鏡頭。嚴禁因屬於同場景而一律機械式合併。

## 3. 空間定位、軸線與構圖

* **複雜群戲定標**：三人以上之複雜群戲，按需於表外繪製站位俯視圖與 180 度軸線關係，標明角色初始與走位座標。
* **9:16 直式構圖**：強調前景、中景、後景之縱深層次，善用前景遮擋與空間透視避免畫面扁平。
* **方向與姿態界定**：
  * 嚴格區分「觀看視角的畫左／畫右」與「角色本身的生理左／右」。
  * 清楚標記角色身體朝向、頭部朝向、視線方向（Line of Sight）及手持道具歸屬。
* **反打與軸線保護**：正反打鏡頭視線必須嚴格互補（如 A 望向畫右，B 望向畫左）。若需越軸，應透過角色走位引導、中性鏡頭（騎軸鏡）或全景空鏡重新建立空間軸線。

## 4. 動作設計與受擊呈現

* **動作節奏拆分**：多招對決或複雜武打可依「起手 → 拆招 → 結果」分鏡調度；單次突襲或瞬間刺殺則一鏡落定，不過度碎切，不強套固定鏡頭數量。
* **受擊視覺反饋**：受擊鏡頭可彈性運用側面切入、同側過肩、畫外入拳及衝擊餘波（如震退、揚塵、環境破壞），明確交代施力方向與道具動線。

## 5. 首尾幀與姿態控制

* **首尾狀態錨定**：首幀（First Frame）僅呈現鏡頭起始狀態，尾幀（Last Frame）僅呈現動作結束狀態，禁止在首尾幀偷跑過渡動作。
* **微調與反打視角**：同機位或視角微調鏡頭，可基於已確認之首幀進行改繪微調；大角度正反打切換時，必須改用匹配該視角之場景與角色資產卡，遵循圖像工具規範。

## 6. 鏡號管理與異動原則

* **鏡號改序**：鏡號順序調整時保留原編號歷史記錄，便於版本比對追蹤。
* **插入與拆分**：插入鏡頭使用後綴新號（如 `03a` 或 `03.1`）；拆鏡時原主段保留原號，新拆出段落啟用新號。
* **合併與推翻**：鏡頭合併或整鏡推翻重構時，舊編號宣告停用並啟用新號，已廢棄之鏡號絕不重複挪用。
* **連鎖檢查**：鏡號任何變動均須同步校核關聯之 generation、參考圖計畫、相鄰鏡頭，並將 QA 狀態退回待審。

## 7. 時間、重疊與群戲反應

* **動作微重疊**：自然剪輯之動作微重疊（Overlapping Action）或有意的高潮動作多角重播（Action Replay）、時間跳切（Jump Cut）均可於表中明確標示，不予機械式禁止。
* **群戲反應分層**：多人反應鏡頭依角色的知情程度與當下處境進行心理層次劃分；無狀態變化之角色不填寫無效動作，不強套「先眼神後肢體」之固定順序，亦不限制 1.5 秒硬性時長。

## 8. 音效、音樂與介面避讓

* **聲源懸念維護**：未知或懸疑畫外聲源（O.S.），畫面／聲音呈現不得提前揭露身分；原劇本台詞與說話者標記仍逐字保留，不為藏懸念擅改原稿。
* **介面避讓**：僅在已知平台具備 UI 遮擋（如短影音右側互動按鈕、底部標題安全區）時，才進行特定構圖避讓。
* **跨鏡音樂**：背景音樂（BGM）可依使用者需求於表外規劃起訖區間、戲劇功能與淡入淡出（Fade-in / Fade-out）；跨鏡頭之對白不重複書寫。
