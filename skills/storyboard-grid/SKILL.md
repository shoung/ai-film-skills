# Storyboard Grid（25宮格分鏡草圖生成規範）

本次對話首次使用時，由主代理依 [版本檢查](../screenplay-director/references/skill-update-check.md) 核對一次。單獨安裝時，以實際安裝的 Git 提交或 `.ai-film-skills-revision` 比對 [上游 main](https://github.com/shoung/ai-film-skills/commits/main/)。有新版先確認是否更新，無法驗證則簡述後繼續。

依既有分鏡實際生成 5×5 PNG 草圖，讓讀者核對構圖及敘事連續性。每鏡保留原表內容及順序，草圖供預覽與核對。正式影片、資產及首尾幀另循其製作流程。

## 生成前檢查

在呼叫生圖或編輯工具前查完本批次。必要資料缺少時，列出缺項、已知路徑與受影響鏡號，停止整批生成，待確認或補妥後再開始。

1. **分鏡表**。確認要用的版本。接受可解析的既有格式；每鏡須有唯一原鏡號，以及足以繪製的畫面與構圖。空表或版本無法判定時先釐清。
2. **正式資產卡**。確認已採用版本，可由使用者或外部工具建立。對回本次分鏡中的角色、場景、重要道具及有效狀態。
3. **參考實圖**。逐張檢查與正式卡對應且可讀的圖片。可用清楚對應的內嵌圖；僅有文字、計畫素材、失效路徑或損壞圖片視同缺圖。僅檢查本批使用的資產。依 [參考圖控制](../film-quality-control/references/reference-control.md) 核對用途。
4. **畫幅**。用專案指定畫幅。畫幅缺失、衝突或混合且無預定交付方式時，先向使用者確認。

## 網格規格

- 每頁 5 欄 5 列。依原表順序自左向右、自上而下，一鏡一格。保留不連號的原編號，各頁最多 25 鏡（25 鏡一頁，26 鏡兩頁）。末頁未用格純白且無編號。
- 畫布與單格均精確符合專案畫幅。寬與高須可被 5 整除，例如 16:9 頁面為 3200×1800，單格 640×360；9:16 將長寬對調。以細實線分格，格線不額外佔用版面。全頁無格間留白、畫框外邊或拉伸變形，保留關鍵構圖。
- 每個有效格左上角只放原鏡號。頁碼、題名、字幕、對白、運鏡箭頭、資產代號、浮水印與說明置於圖外。

## 繪製與合版

依原分鏡的機位、景別、視線與前後動作，為每個連續鏡頭繪製一個代表瞬間。用黑白或灰階線稿表現角色、場景、道具及有效狀態；識別或敘事需要時保留局部色彩。實看參考，依 [跨場資產連續性](../film-quality-control/references/asset-continuity.md) 維持固定布局與適用狀態。場景示意圖的站位標記用於核對，留在示意圖上。

每頁請求自足，實際提交該頁使用的圖片與分鏡資料。提示詞創作依 [寫作分流](../antigravity-writer/SKILL.md) 或 [單獨安裝備援](references/writer-fallback.md) 執行，按實際證據回報。

工具的附件數量或尺寸不足時，可在工具支援下逐鏡生成，以程式合版並覆寫左上角的原鏡號。按鏡頭提交所需實圖並保留畫幅。實圖、工具或可行合版方式不足時，回報阻礙；此任務的交付為圖像檔。

## 複核與交付

逐頁逐格實際查看，核對：

- 頁數、5×5 格線、無格間留白、畫布與單格畫幅。
- 由左至右、由上至下與原表一一對應，鏡號清晰；末頁未用格純白且未編號。
- 資產與正式參考相符，景別、構圖、代表動作、空間連續性及圖內標記符合規格。

依 [影像品管](../film-quality-control/SKILL.md) 安排獨立視覺複核。獨立審核不可用或無法看圖時，在圖外標「待審」並記原因。只修有錯的鏡頭，合版後複核受影響頁面。

儲存在專案的分鏡草圖子目錄，每批新建子目錄，PNG 從 `storyboard-grid-001.png` 起編，保留既有批次。回報檔案連結、頁數與原鏡號範圍、查核結果及待審事項。草圖可在 [創作台](../film-workbench/SKILL.md) 瀏覽，品管結果以獨立證據為準。只在接到草圖生成任務時執行本流程。
