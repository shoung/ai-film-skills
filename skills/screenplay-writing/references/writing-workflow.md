# 劇本寫作與修訂

## 選擇工作範圍

| 工作 | 讀取的資料與交付 |
| --- | --- |
| 初稿或依大綱擴寫 | 讀核准綱要及本案必要的人物、世界、調性和約束。採用專案檔或已確認的同等資訊。交付指定場次、集數或全稿，附相關版本和重要未決事項。 |
| 續寫 | 讀最新版已完成段落與下一個節點。承接時間、空間、人物目標、知情、角色語感和道具狀態。 |
| 局部或結構修訂 | 讀本次指定範圍及必要前後段。若有會診報告或修改任務，標清採納、暫緩、未採納，核對修訂引發的前後影響。保留未受影響的場次和作者指定的內容。 |
| 台詞整合 | 以劇本版本、場次與原句定位已採納的替換。改動若影響因果、角色關係或場次，另行標出並依授權處理，必要時回結構修訂。驗證角色語言一致性。 |
| 純轉檔 | 直接讀來源並沿用已知結構、編號、台詞與鎖定內容。依 [劇本格式](script-formats.md) 轉換。 |

鎖定台詞的字詞、標點、語言、說話者與順序沿用原稿，除非作者已核准變更。核准後更新鎖稿版本，重新核對受影響的分鏡和生成提示詞。角色只有一人、專案用簡檔或無「性格三層」欄位時，依已有可信的人物描述及實際言行維持一致性。

有對標分析時，用已核准規律支持相關創作決策並標出實例。不確定的設定附於製作筆記；使用者授權代決的項目依本輪處理。使用者指定格式、節奏、場次或集數時直接沿用，只確認會改變交付的重大缺項。

## 節奏與分批

以下供工作選擇。詞語可用繁簡同義詞或自然語言表達，也支援 `開始寫作 模式=標準 節奏=短劇`、`#小說化 #微電影`、`/重寫第X場`、`/重寫第X集`、`/對白調優`、`/擴寫`、`/減字`、`/節拍檢查` 和 `批量模式`。著手寫作後切換格式或節奏時，先確定調整影響的既有段落。

| 常用節奏 | 核對重點 |
| --- | --- |
| 短劇 | 及早建立可見衝突，讓每次轉折改變局勢。集尾由本集結果生出下一個問題。 |
| 連續劇 | 主副線交織，角色知情和做出的選擇跨集累積。 |
| 短影片 | 選明確的核心訊息，安排觀眾能在本片理解的視聽轉折。 |
| 單元劇 | 本集先解決現在的事件，視需要推進系列世界或人物弧線。 |
| 微電影 | 讓有限場次集中於同一核心情感或行動，保留結尾需要的餘韻。 |
| 長篇電影 | 依本案結構安排關鍵抉擇、阻力升級及高潮，檢查次線如何改變主線。 |

按媒介、目標時長與實際表演調整節拍，不套固定秒點或三幕比例。篇幅大時在完整場、集或幕的邊界分批，保留上下文、受影響的前後段、完成範圍、待續位置和版本。已核准的格式與風格可連續交付；試稿在風格尚待驗證或委託要求時使用。分批遇新指示時先判斷影響，按本輪授權更新相應段落及後續計畫。

## 交付前核對

核對劇情因果、人物語言、本輪鎖定項和相鄰場承接。完整稿可依用途附場次、篇幅、估計時長、採納事項、需下游處理的問題與估計依據。將版本、討論及製作備註留在正文外。用 [劇本格式與製作交接](script-formats.md#拍攝配音與分鏡銜接) 檢查後續有拍攝、配音或影片提示詞需求的劇本。
