# 表演控制共通規則：MiniMax H3 / Seedance

本規則適用於人物表演提示詞，涵蓋對白、反應與日常動作。情境需要時提供鏡頭可見動作與動勢。

## 1. 內部思考鏈與提示詞正文
思考鏈（角色目標、起點轉變、觸發點、停頓、可見證據、防止提前反應）供創作者內部推演，非強制欄位。正文呈現精煉主幹動作，不強制輸出六欄或編號子節拍。

## 2. 表演動作與鏡頭可讀性
- **自然動勢**：視線與頭部隨情境自然協調，不設定僵化順序。
- **單一動作鏈**：維持清晰主線（如伸手取物、飲用、放回），避免矛盾多工。
- **直觀運鏡**：使用推近、拉遠、平移、固定等通俗術語，不堆砌焦段數值，不與固定機位矛盾。
- **杜絕微動作填料**：不加入無目的眨眼、抓衣角等瑣碎動作。
- **情緒表現**：強烈情緒需有明確事件觸發，配合可見動作自然流露。

## 3. 模型格式整合
### Seedance
- 欄位為選用，預設採用自然段落敘述。
- 參考標籤 `@標籤` 與前後中文內文需以空格分隔（如 ` @人物甲 `）。
- 內文使用繁體中文，運鏡直觀明確。

### MiniMax H3
- **基礎模式**：維持三欄（`integrated_multimodal_description:`、`overall_soundscape:`、`non_diegetic_music:`）。
- **全參考模式**：維持六欄（`subject_definitions:`、`summary:`、`retention_analysis:`、`detailed_description:`、`overall_soundscape:`、`non_diegetic_music:`）。
- 主體敘述使用繁體中文，保留英文語法標籤（`[Shot 1]`、`At 00:00.000`、`<d>[Chinese] ...</d>`、`(S1)`、`N/A`）。
- 語氣置於 `<d>` 外，`<d>` 內僅保留實際台詞。

## 4. 輸出前核對
- 原台詞逐字保留，動作為乾淨主幹動作鏈，無多餘微動作填料。
- 運鏡直觀無矛盾，製作備註隔離於提示詞正文之外。
