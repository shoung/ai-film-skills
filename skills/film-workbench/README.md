# 本地 AI 影視創作台

以 drama-skills 固定版本 `37232f6` 的創作台為介面基礎，使用 Python 標準庫及原生 HTML/CSS/JS；原文件為真源。

```powershell
python scripts/dashboard_server.py "D:/你的專案" --port 0 --detach --open
```

更新程式後，先用同一專案路徑執行 `--stop` 再重開；`--status` 可查看現有服務。僅供本機使用，啟動網址中的 Token 不應公開。

## 閱讀流程

全劇總覽提供分集製作進度與下一步。進入一集後，從頂部切換概況、劇本、設定、分鏡、提示詞、成片、審查；全部檔案是次級入口。

分鏡可切換卡片／表格，主表固定八欄。選鏡後在同一詳情閱讀圖、首尾幀、可用片段、台詞、關聯設定、提示詞與審查；桌面圖詞並排，窄版上下排列。提示詞可展開及複製。只有整張宮格時會保留整圖和鏡號範圍，不能當成單鏡已生圖。

圖片或影片多候選不代表已採用；有剪輯單才按真實剪輯資料顯示時間線。沒有成片、剪輯或審查時顯示缺項，不以零值或預設通過冒充完成。

## 八欄與既有專案

欄序為：編號、畫面描述、攝影機描述、聲音描述、旁白對白、時長、影片生成方式、畫面prompt。舊九欄多出的「修改」保留為附註，匯入不刪欄或重寫文件。

同鏡的 MD／CSV 保留各來源；有內容差異時先閱讀候選，確認源文件再編輯。不同版本各自分組。素材依登錄、連結及有邊界的鏡號命名關聯，缺失或歧義會提示；無法辨識的內容仍可讀原文。舊 QA 紀錄不能自動升格為正式套件的通過證據。

## 編輯與 QA

從各階段「編輯原文」進入文件編輯。保存只寫原文，不執行生成、渲染或批准審查。外部修改造成的版本衝突返回 409，需重新讀取後合併。QA JSON 保持唯讀，修改創作資料後依 `film-quality-control` 重新審核。
